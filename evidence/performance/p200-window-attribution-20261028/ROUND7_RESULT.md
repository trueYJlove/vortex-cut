## 2. 按预注册判据判读

预注册判据（原文）：

- **A**：≥3 次运行中 ≥2 次出现「连续 2 段 ≤1 帧/秒」⇒ 停摆**可复现**
- **B**：全部运行最大 compose 间隔 <1000ms ⇒ 停摆**未复现**
- **C**：介于两者 ⇒ **不确定**

四次运行的 `compose` 间隔均未出现「连续 2 段 ≤1 帧/秒」的形态（三次 3 分钟复跑 `reached_end=true`、
上传 p95 3.0–3.9ms、解码 p95 ≤6.0ms，处于健康区间）⇒ **不满足 A**。
但 `869-r1` 那次仍以超时中断、`reached_end=false` ⇒ **也不能判 B**。

### 判定：**C（不确定）** —— 不得下结论

**必须同时说明的两点，缺一即为过度解读**：

1. **未复现 ≠ 产品没问题**：三次复跑用的是 **165.58s / 4967 帧**夹具，而 `869-r1` 是 **869s / 26083 帧**。
   观察窗**不同**（3 min vs 16 min），本组根本不覆盖 869s 的长度档位 ⇒ 对「长时线停摆」**无判别力**。
2. **未复现 ≠ 缺陷不存在**：`869-r1` 有真实遥测（`reached_end=false` + `RANGE_READ_TIMEOUT`），
   该次运行的失败是**证据**，不是噪声。

## 3. 本轮唯一新增的确定事实

`869-r1` 的 `RANGE_READ_TIMEOUT: 采样 22477 字节读取超时（10s）` 此前**未登记**。
它把「P200 长时线停摆」与**分段采样读取超时**这两件事首次放在同一次运行里。

**等级：观测（observation）**——只有一次运行、无对照，不得据此归因。
按 `ATTRIBUTION_ROUND6.md` §8 口径，下一步若要推进，须先做**同长度档位（≥14 分钟）的重复运行**，
而不是继续在 3 分钟夹具上重复「未能复现」。

## 4. 结论对 P200 状态的影响

**不变**：P200 仍为「现象已实证、根因未定」。
本轮的贡献是**否证了一种推进方式**——用短夹具重复「未复现」无法证伪长时线问题；
以及**新增了一条可跟踪的观测**（`RANGE_READ_TIMEOUT`，见上）。

# W2.2 「细切 + 按份额合并」预登记（ADR-0008 D2-a / D3-a）

> **本文件在任何判定集读数产生之前写定**（时间戳见文末）。
> 依据：`docs/design/adr/0008-w22-o2-rerecheck.md` D2-a / D3-a 与 **§4 的七条硬约束**。
> 复裁决背景读数（探索性、非本预登记的一部分）：`evidence/2026-10-14-w22-p-finecut-recheck/`。

## 0. 要回答的问题（**一个**）

> **「细切 + 按份额合并」这一固定参数形态，能否在未被读过、人数为 4–20 的语料上，
> 同时（i）过 AMI 级门限、（ii）不劣于现行准则、（iii）把它打不过的地方如实记账？**

## 1. 形态定义（**冻结，不得执行期增补**）

```
输入：窗 embedding（已缓存，campplus）× 窗集合（silero VAD）
 1) 细切：在 τ 网格上取「簇数 <= Kf 的最大簇数」对应的 τ
 2) 合并：把份额 < s 的簇并入最近的（质心余弦）大簇
     guard：若没有任何簇达到 s，则锚定最大簇作为唯一大簇（**规格的一部分**）
 3) 输出 labels -> windows_to_turns -> DER
```

- τ 网格、窗长、跳长、VAD、模型**一律沿用现役冻结值**（门 §4），本形态**不动它们**。
- **不做**：不改准则、不改聚类族、不改特征、不改产品参数 `k_max`。

## 2. 语料角色（**三集分离**）

| 角色 | 语料 | 场次 | 状态 |
|---|---|---|---|
| **定参集** | **AMI dev** | 18（K=4×18） | 本仓**从未用过** ⇒ 干净 |
| **判定集（主）** | **VoxConverse 未读子集** | **56**（K=4–20，见 §3） | 从未跑过任何 DER ⇒ 干净 |
| **对照（不劣化）** | AISHELL-4 test | 20 | **本轮已读** ⇒ 只作对照 |
| 参考（只报不改参数） | AMI test / VoxConverse test K<=3 | 16 / 63 | **已读** ⇒ 只作参考 |

**为什么判定集是 VoxConverse 未读子集而不是 AMI test**：AMI test 与 VoxConverse test K<=3
在 ADR-0008 复核里都已读过 ⇒ **不能充当盲测**。本判定集与已读集合**交集为空**（可复核）。

## 3. 判定集选择规则（**看任何 DER 之前定死**）

- 源：VoxConverse（CC BY 4.0）本地 wav，**排除**已读集合（test-lowk 64 + dev-48 + highk 49）；
- 过滤：时长 >= 120 s；按真值人数分档 **4–6 / 7–9 / 10+**；
- 每档**按名称排序取前 20**（不是按性能挑）；末档不足 20 则全取 ⇒ 实际 **20 / 20 / 16 = 56**；
- 清单：`.tmp/vc-subset-judge.json`（含 `selected`，可逐场复核）。

⚠️ 该语料的 DER 绝对值**不可**与 AMI/AISHELL-4 比大小（YouTube 真实对话，录音条件不同）；
本判定**只用它做三件事**：是否过门、是否打得过常数基线、是否不劣于现行准则。

## 4. 定参（**已冻结，见 `tuning-freeze.json`**）

- 网格：`Kf ∈ {12,16,24,32,40,48,56,64}` × `s ∈ {0.02,0.05,0.10,0.15}`（32 点，**全报**）；
- 可过点：AMI dev 上 **两种重叠口径都**满足 `mean <= 0.40 且 worst <= 0.60`；
- 选择：**margin 最大**者（`margin = min(0.40 - max(mean_T, mean_F), 0.60 - max(worst_T, worst_F))`），
  并列时取**更小 Kf**、再取**更小 s**；
- 若可过点为空 ⇒ **参数冻结失败，本实验终止**（不得改判据续做）。

## 5. 判据（**看数之前写死**）

### 5.1 主判定（判定集 = VoxConverse 未读 56 场）

| # | 条件 |
|---|---|
| **M1** | 冻结参数在判定集上**两种口径都**不劣于现行 `silhouette+capK=8`：`mean_new <= mean_base + 0.02` 且 `worst_new <= worst_base + 0.02` |
| **M2** | **反平凡性**：冻结参数在同判定集上**严格优于**「恒取 K=c」常数基线族（`c ∈ {2,3,4,5}`，同一棵树上取最接近 c 的割）中**均值最好**者 |
| **M3** | **（a）分支如实报告**：输出 K=1 的场次数、其中真值 K=1 的比例（精确率）、漏掉的真值 K=1 场次（召回） |
| **M4** | **假阳性代价如实报告**：K<=3 档（若判定集内存在）与整体 mean 的变化；与现行准则逐场 `improved / equal / worse` 计数 |
| **M5** | **参数敏感度**：定参集上 margin 排序**前 5 名**逐个在判定集上重算并**全报**（证明结论不依赖「恰好挑中的那一个点」） |

### 5.2 对照（不劣化）

| # | 条件 |
|---|---|
| **C1** | AISHELL-4：两口径均 `mean <= 0.40 且 worst <= 0.55`（该语料门限），且 `mean <= 基线 + 0.02` |
| **C2** | AMI test（参考，不改参数）：两口径均报 `mean / worst`，与复核读数一致（±0.001 视为复现） |
| **C3** | VoxConverse test K<=3（参考，不改参数）：如实报与基线的差异，**不得**因它退化而调参 |

### 5.3 采用条件（**全部满足**）

```
M1 and M2 and C1  =>  建议落 Core（仍须 S3 精度门在生产链路上复核）
否则               =>  不落 Core，如实报告（含 M3–M5 的代价读数）
```

## 6. 必须报的**负向对照**（证明判据有区分力，不是恒真）

| # | 对照 | 预期 |
|---|---|---|
| NC1 | 去掉合并 guard（无簇达标时返回原割） | 判定集上 worst 显著恶化（复核期实测 K≈40、DER≈0.98） |
| NC2 | 只细切不合并（`s=0`） | 不达 M2 |
| NC3 | 只合并不细切（`Kf=8`） | 不达 M1/M2（复核期实测几乎无变化） |
| NC4 | 现行 `silhouette+capK=8` | 不得被 M2 的常数基线判为达标（否则 M2 失效） |
| NC5 | 把定参集换成 AMI test（**违规对照**，只做一次） | margin 区间明显不同 ⇒ 证明换定参集结论会变，故定参集不可事后更换 |

## 7. 污染声明（**必须与结论同读**）

- **设计期已看过**：AMI test 与 VoxConverse test K<=3 的读数（ADR-0008 复核），
  以及 AMI dev 的 K 分布（K=4×18，来自 RTTM，非 DER）。
- **本预登记写定时未看过**：判定集 56 场的**任何 DER**。
- ⇒ 判定集**干净**；但**形态本身来自被污染的观察**（复核期发现的「细切+合并」）⇒
  本实验**不能**证明「发现了新机制」，**只能**证伪或未能证伪「该形态可用」。

## 8. 边界（不判的事）

- **不判**生产链路上的耗时/内存（本实验用缓存 embedding）；
- **不判** S3 精度门（需生产 `SpeakerDiarizationService`）；
- **不判** >20 人档；
- **不判**最优性（只判「是否可用」）。

## 10. ⚠️ 执行期发现（**跑数之后追加；上文字句一律不改**）

> 按本包惯例：预登记一经写定**不得事后修改**；执行期的发现**追加在本节**。

### 10.1 §4 的定参成功，但**定参点的选择不稳健**（本实验最重要的执行期发现）

- AMI dev 上 **13/32** 点可过；冻结 `Kf=24, s=0.05`（margin 最大 +0.0876）。
- **M5 实测**：定参 margin 前 5 名逐判，**1 点（kf=48,s=0.05）在判定集上不达 M1**。
- **NC5 实测**：AMI test 上仅 **5/32** 可过且会冻结到**另一个点**（kf=40,s=0.10），
  而 dev 冻结点在 AMI test 上 **margin 为负** ⇒ **两集可用区几乎不相交**。
⇒ §5.14 判定四登记的「单阈值 + 小样本定参」共性风险**第三次命中**。

### 10.2 §6 的 NC1（去 guard）**在本配置下无区分力**

判定集 / AMI test / AISHELL-4 上，去 guard 与带 guard 的读数**逐位相同** ⇒
guard 在该配置下**从未触发**。§5.18 的「guard 是规格的一部分」**仍然成立**
（复核期 `Kf=40` 配置下实测 DER 0.9833），但**本轮它不构成一条对照**。
⇒ 下一轮预登记须**给 guard 单独构造触发条件**，否则该对照形同虚设。

### 10.3 §5.1 的 M2（反平凡性）**被证明无区分力**（NC4）

**现行准则同样优于「恒取 K=2..5」常数基线中的最优者**（0.2508 < 0.2688）⇒
「通过 M2」**不构成**「优于现行」的证据 ⇒ **M2 须替换为「与现行准则直接对照」**。

### 10.4 判定集的分档结果表明该形态**不能同时服务两端**

按真值 K 分档（判定集 56 场）：**4–6 档 9 好 11 差**（净损失）、**7–9 档 13 好 7 差**、**10+ 档 10 好 6 差**；
而**参考集 VoxConverse test K≤3 大幅退化（47/63 更差）**、**K=1 分支在冻结配置下退出**。
⇒ 与 §5.1 的 M4 只要求「如实报告」相比，本实验暴露的是**产品取舍**（低人数档 vs 高人数档）。

### 10.5 判定口径未变

§5 的判据、门限、语料角色**一律未改**；`ADOPT = true` 是**按原判据**得出的。
本节的四条发现**不改变**该字面结论，只改变**它的可用性与解释**。

# W3.3 关键帧打标人工盲评 —— 预登记

> **本文件在跑任何评分之前写定**（评分维度、抽样规则、统计口径、结论上限）。
> 依据：规划门 M4（判据先预登记后看数）/ 评审 M4 / Design Gate A9。
> 日期：2026-10-21

---

## 0. 为什么需要人工盲评，而不是自动化判分

Design Gate D3 已裁决：**打标质量没有客观真值**。

具体到本功能：一张 768px 关键帧「应该」被打什么标签，取决于观看者的判断与用途，
不存在一个可自动比对的 ground truth。这一点与 W2.2 说话人分离（有 RTTM 标注可比）**根本不同**，
也与 W3.1 检索（可用「查询是否命中目标品类」近似）不同。

因此本评测**只回答一个问题**：

> 模型给出的标签，人看了之后认为「合理 / 部分合理 / 不合理」的比例各是多少？

**明确不回答**：① 与其他模型比谁更好（无对照）；② 与人工标注的 F1（无标注）；
③ 「可用于生产」（单次盲评给不出该结论）。

---

## 1. 抽样规则（先定死，不看数据后调整）

| 项 | 规则 |
|---|---|
| 素材来源 | 盲评包构建时**按素材 ID 排序取前 N 个可用视频素材**（不挑「好看的」） |
| 帧来源 | 每个素材用 **S1b 的抽样计划**（切点优先 + 间隔兜底，封顶 24）——**不是另抽一套**，否则评的不是生产链路 |
| 帧数 | 每个素材取**前 3 帧**（按 frame_index 升序），控制总评分工作量 |
| 素材数 | 取 **5 个素材**（合计 15 帧；若素材不足则如实标注实际数） |
| 排除项 | 素材不可用 / 无视频流 / 打标失败 **不进盲评包**，并在报告中如实列出被排除数量 |

**为什么固定取「前 3 帧」而不是随机**：随机抽样需要随机种子与可复现性说明；
固定规则更容易被独立复算，且 3 帧已能覆盖同一素材内的多样性（切点/间隔混合）。

---

## 2. 评分维度与判定口径（三档，强制选择）

评分者对**每一帧**给出三档之一：

| 档位 | 判定标准 |
|---|---|
| **合理** | 标签正确描述了画面中的主要内容；或返回空标签且 notes 明确说明「无可匹配标签」而画面确实不属于任何词表类目 |
| **部分合理** | 标签沾边但不准确（如「室内」用于半室外场景）；或漏掉了画面中最显眼的主体 |
| **不合理** | 标签与画面主要内容矛盾；或把明显属于某类目的画面判成空标签 |

**关于空标签的特别约定**（必须写清，否则评分者会把它当成失败）：

`labels=[]` 本身**不是**失败。判定依据是 notes：
- notes 说明「画面不属于任何词表类目」且属实 ⇒ 「合理」；
- notes 为空或与画面矛盾 ⇒ 「不合理」。

**不作为评分依据的东西**：① 响应耗时；② notes 的文案风格；③ 标签数量多少。

---

## 3. 统计口径（先定死）

主指标：`合理率 = 合理帧数 / 参与评分帧数`。

辅助（只报不设门槛）：部分合理率、不合理率、空标签帧占比、词表违规帧数。

**样本量限制（必须与结果同报）**：15 帧的 95% 置信区间宽度约 **±25 个百分点**——
即 12/15 与 15/15 在统计上**无法区分**。因此：

- 本评测**不设通过/不通过门槛**；
- 结论只能写成「在 15 帧上观察到 X 档 Y 帧」，**不得**推广为「该模型打标准确率 X%」；
- 若评分者认为样本不足，可随时扩大 N 重跑，但**规则不得因结果而修改**。

---

## 4. 盲评如何做到「盲」

盲评包**不包含**：模型名称、Provider 名称、相似度分数、生成时间。
每帧只给：`样张编号 / 图片文件 / 帧时间戳 / 该帧的标签与 notes`。

**已知局限（如实登记）**：评分者知道标签来自哪个功能（Layer 2 关键帧理解），
这无法完全隐藏。但评分者**不知道**具体是哪次运行、哪张图对应哪次调用，
也不掌握本次评分的预期方向——这已能避免最明显的期望效应。

## 5. 交付物

| 文件 | 内容 |
|---|---|
| `frames/` | 逐帧 JPEG（文件名 = 样张编号，不含素材名） |
| `score-sheet.md` | 逐帧评分表（编号 / 标签 / notes / 三档勾选） |
| `manifest.json` | 样张编号 ↔ 素材/帧的映射（**评分完成后再看**，用于可复算） |
| `summarize.py` | 读评分表算主指标与辅助指标，输出 `result.json` |

---

## 6. 结论上限（写死在前面）

**无论结果如何**，本评测都**不得**被引用来支持以下表述：

- 「关键帧打标准确率 N%」（单次 15 帧支撑不了）；
- 「比 X 模型好 / 差」（无对照）；
- 「可用于生产」（需要的是持续回归集，不是一次性盲评）；
- 「质量已通过验收」（A9 的关闭条件是**用户完成评分**，不是分数高）。

**允许**的表述：「在 N 帧的人工盲评中，合理 X 帧、部分合理 Y 帧、不合理 Z 帧」。

## 7. 与 A9 的关系

Design Gate A9 的判据是：**盲评包的判据与统计口径先于看数预登记**（即本文件）+ 盲评包可独立运行。
**A9 不要求分数达标**——它要求的是「口径诚实、可复算、不越界表述」。

P165（用户评分待完成）由此**仍然保持开放**，直到用户实际完成评分。

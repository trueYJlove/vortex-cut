# W2.2 K 估计器 spike —— **预登记**（看数之前定死）

> 2026-10-13。本文件在**运行任何候选估计器之前**写定。

## 0. 为什么做这个（§5.11 留下的根因）

门 §5.11 判定三把失败根因定位为：**K 估计是硬约束，而它会低估**——
G1 的残差 worst 不是"选错"，而是"正确答案不在候选集里"。
⇒ 下一步不是再换选择准则，而是**把"这个素材有几个说话人"做准**（或放弃硬约束）。

同时，门 §5.6④ 的**第一条**不批准理由就写着：

> "它依赖的说话人数估计器**从未被单独验证质量**——该规则的输入本身是未验证的"。

本 spike 首先补上这一课，再谈改进。

## 1. 第一阶段：**先测量现役估计器**（不改进，只测量）

现役估计器（生产代码 `speaker.choose_threshold_distance_mixture` 内联）：
`K_hat_dm = clip(round(1 / w_same), 1, 8)`，其中 `w_same` 是两成分高斯混合中低距离成分的权重。

**必须报的读数（门 §5.11 判定五要求双向）**：

| 读数 | 为什么 |
|---|---|
| 命中 / **高估** / **低估** 比例 | 高估与低估**处方相反**（§5.11 判定五） |
| `err = K_hat - K_true` 的 mean/median/\|err\| | 偏差方向与量级 |
| **`r(K_hat, K_true)`** | 估计器**是否携带信息**——本阶段的**关键判据** |
| 按 K_true 分组 | 是否只在某一档可用 |

### 1.1 预先声明的判据（**看数之前**）

- **P1**：若 `r < 0.3` ⇒ 估计器**基本无信息**，任何"以 K_hat 为硬约束"的规则都不可靠，
  **无论**上界还是下界。此时**直接进入阶段二**（换估计器或放弃硬约束），
  **不再**在原地调参。
- **P2**：若低估与高估**同时**都显著（各 >=20%）⇒ **单侧修正（加 margin）治不了**，
  必须双向处理。
- **P3**：反平凡性——一个"恒取中位数"的常数估计器也能有不错的命中率，
  故**必须**同时报 `r` 与"相对恒取常数的增量"。

## 2. 第二阶段：候选估计器（**先定死，不再增补**）

全部只用**同一素材自己的**嵌入，不偷看真值。

| 代号 | 定义 | 动机 |
|---|---|---|
| **E0** | 现役 `round(1/w_same)` | 基线 |
| **E1** | **本征维/有效秩**：对窗嵌入协方差做 PCA，取解释 90% 方差的主成分数 | 直接问"数据里有多少个独立方向"，比重尾分布更接近"几个人" |
| **E2** | **合并距离最大间隙**：层次聚类合并距离序列的最大 gap 处的簇数 | 经典 elbow 思路，但用间隙**比值**而非绝对值 |
| **E3** | **双窗一致性投票**：窗集合对半分，两半各自用 E0 估计，取中位数并要求一致 | 针对 E0 的不稳定；一致性可当置信度 |

**已知约束（写着，避免事后惊讶）**：

- 所有候选仍受 `k_max=8` 封顶（门 §10 O2）；
- 语料真值覆盖 K=1..21 不等，但**主判定语料是 K<=3**；
- 阶段二**不判**"哪个估计器能过精度门"——那是 S3 的事。本 spike 只回答"估计器本身好不好"。

## 3. 判定口径（**看数之前写死**）

### 3.1 主读数

- **主判定语料**：VoxConverse test K<=3（63 场，产品主场景）；
- **对照**：AMI（16 场）、AISHELL-4（20 场）；
- **指标**：命中率、双向偏差率、`|err|`、**`r(K_hat, K_true)`**。

### 3.2 采用条件（**三条全过**才建议落 Core）

| # | 条件 |
|---|---|
| K1 | 主判定语料 `r` 显著改善：E 相对 E0 提升 >= **0.3**（绝对） |
| K2 | **双向都不偏**：高估率与低估率**各自** <= **25%**（主判定语料） |
| K3 | **不在对照语料上退化**：AMI 与 AISHELL-4 上 `r` 不低于 E0 超过 0.05 |

### 3.3 必须同时报告

1. **反平凡性**：与"恒取常数"（取中位数）对照；
2. **双向偏差**（§5.11 判定五）；
3. **组内明细**：哪些场变好/变差；
4. **成本**：新增计算量（产品要付的代价）。

### 3.4 明确**不**判定的事项

- **不判**精度门（DER）：估计器变好**不等于**最终 DER 变好（还需选择准则配合）；
- **不判**"能否输出 K=1"：该结构性问题（§5.10 判定四）需单独设计。

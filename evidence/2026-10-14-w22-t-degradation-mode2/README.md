# W2.2 降级交付 口径 2（只交付高置信区间）—— 可行性实测（2026-10-14）

> 动机：ADR-0006 D4/C 的降级交付讨论中，**口径 2**（低置信段不输出、宁可少报）被认为
> 最能对冲 W2.2 的已知失败模式（**欠分割**：把多人并成一个）。
> 本目录在**采纳该口径之前**实测它是否真的成立——**结论：在「最差场」这条线上不成立**。

## 方法（无真值参与选择）

逐窗置信度 = **margin** = `d2 − d1`（到次优质心的余弦距离减去到最优质心的余弦距离），
再归一化为**帧级 mask**（重叠窗取最大 margin）。按 target coverage 取 margin 分位阈，
**只在保留下来的计分帧上算 DER**（其余帧既不报也不计）。语料：AMI test 16 + AISHELL-4 test 20。

## 结果一：池化（pooled）曲线看起来很好

| 覆盖率 | AMI 选择性 DER | 中文选择性 DER |
|---|---|---|
| 100% | 0.4540 | 0.2604 |
| 70% | **0.3180** | **0.1407** |
| 50% | **0.2581** | **0.1188** |

⇒ 池化均值随覆盖率下降而**显著改善**（AMI 0.4540→0.2581）。

## 结果二（决定性）：**最差场几乎不改善，中文甚至变差**

| 覆盖率 | AMI 最差场 | 中文最差场 |
|---|---|---|
| 100% | 0.7016 | 0.7636 |
| **70%** | **0.6330** | **0.7471** |
| **50%** | **0.6308** | **0.7875**（**变差**） |

- AMI 最差场 0.7016 → 0.6308（**砍掉一半数据只降 0.07**），**仍远高于任何可交付线**。
- **中文最差场在 50% 覆盖率下反而上升到 0.7875** ⇒ 高 margin 帧**不等于**判得对的帧。

## 结果三：失败模式与守卫的错配（机制）

最差场全部是 **欠分割** 场（`ES2004d`/`EN2002d` K=2 vs 真值 4；`M_R003S05C01` K=2 vs 真值 6）。
欠分割时**整场被合并成一个簇**——此时每个窗到「次优质心」的距离都很远 ⇒ **margin 反而很大**
⇒ **置信度指标在它最该报警的地方给出最高分**。

这与 §5.10 已登记的守卫否决**同源**：那里的 `separation` 拒答守卫也拦不住最差的 `euqef`
（收益为零、代价为正）。**本次是同一机制在「逐段交付」口径下的再现**。

## 结论（供降级设计门使用）

1. **口径 2 作为「只交付高置信区间」不成立**——它改善池化均值、**基本不改善最差场**，
   在中文 50% 覆盖率下**使最差场变差**。
2. **不得**以池化曲线（或 mean）为依据采纳该口径——**必须看最差场**。
3. 若要继续降级方向，正确的目标**不是**「挑更自信的段」，而是**先解决欠分割**
   （欠分割是 S3 失败的主因：AMI 10/16、中文 11/20 场为 K ≤ 真值−2）。

## 边界（如实）

- 置信度只测了 `margin` 一种（未扫其他不确定度指标）；
- 覆盖率为**整体目标**，未按场自适应；
- 未涉及真机链路；未改任何生产代码（纯离线测量）。

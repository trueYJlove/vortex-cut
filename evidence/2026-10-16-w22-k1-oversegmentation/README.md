**判定一**：**11/11 场在 τ≥0.60 处都收敛到 K=1** ⇒ 「表达能力」欠账在这里不是「候选集里没有 K=1」，而是**准则选了更低的 τ**。
（与 ADR-0006 判定一一致：K=1 在 τ 网格上可达，但**准则的评分函数不评价 K=1**。）

## 3. 诊断二（**决定性**）：高 τ 的 K=1 **没有区分力**

| τ | K_true=1 命中 | K_true≥2 假阳 | 可用? |
|---|---|---|---|
| 0.50 | 8/11 | 2/27 | 退化 |
| 0.55 | 9/11 | 3/27 | 退化 |
| 0.60 | 10/11 | **6/27** | 退化 |
| 0.65 | 10/11 | 9/27 | 退化 |
| 0.70 | **11/11** | **15/27** | 退化 |
| 0.75 | 11/11 | 19/27 | 退化 |
| 0.80 | 11/11 | **25/27** | 退化 |

**判定二（本诊断最重要的负结果）**：提高 τ **必然**让 K=1 更易出现，但同时把大量多人素材压成 1 ⇒ **这条所谓「发现」没有任何区分力**，**不得**包装成「提升到 K=1 的规则」。与 P119 同型：**能命中现象，不等于能区分**。

## 4. 诊断三：有没有廉价信号能区分 K_true=1 与 K_true=2？（**没有**）

| 信号 | K_true=1（min/中位/max） | K_true=2（min/中位/max） | 是否重叠 |
|---|---|---|---|
| Sa silhouette(K=2) | 0.111 / 0.191 / 0.414 | 0.131 / 0.372 / 0.568 | **重叠** |
| Sb 两簇质心余弦距离 | 0.062 / 0.110 / 0.270 | 0.067 / 0.326 / 0.596 | **重叠** |
| Sc 两簇份额比 | 0.500 / 0.722 / 0.966 | 0.224 / 0.759 / 0.923 | **重叠** |
| Sd 窗数 | 12 / 62 / 112 | 27 / 74 / 107 | **重叠** |

强制单一阈值的最佳可能：`Sa` 命中 10/11 但**假阳 4**；`Sc` 只命中 3/11。

**判定三**：**四个廉价信号在两组分布上全部重叠** ⇒ 在这些窗向量上，**没有「无自由参数」的信号能可靠区分单人与双人素材**。这与 §5.12（K 估计器不携带信息）**同向且更具体**（限定在 1 vs 2 这个最小判别问题）。

## 5. 诚实结论

1. **K=1 是可达的**（τ≥0.60 时 11/11），缺口在**准则不评价 K=1**，不是「没有 K=1」；
2. **但把 τ 提上去是无区分力的退化手段**（τ=0.70 时假阳 15/27）；
3. **也没有廉价替代信号**（四个候选全部重叠）；
4. ⇒ **我目前没有「可产品化地把 K_true=1 判成 1」的方案**。本轮**不提出任何规则**，也不建议据此改代码。

## 0. 为什么要换问题（而不是再造一个门槛）

前两轮我把"可分性"当成研究对象，两次都以**我自己拍的常数**判定，两次都差约 0.01。
⇒ 问题不在数据，在于**我在中间量（ARI）上造门槛**。

**本轮改问一个产品问题**：

> **现行生产链路在产品的「主场景」（1–2 人：口播 / 对谈）上，是否已经达标？**

**为什么这值得问**：
1. **门限是在多人会议语料上定的**（AMI 4 人 / AISHELL-4 5–6 人），而 P114 明确记录
   **「2 人素材（口播／对谈）是产品主场景」** ⇒ **判据与被测对象存在场景错配**，从未被处理；
2. 若主场景达标，则是**唯一不需要任何新算法**就能解锁的路径（W2.3 可在该档开工）；
3. 它**不依赖 oracle 信息**（P133/P134 的致命弱点）——用的是**生产链路真实输出**。

## 1. 判据（**看数之前写死**；锚 = 既有门限，未改任何门限）

### 1.1 前置（决定判据是否有分母）

| # | 条件 | 门槛 | 说明 |
|---|---|---|---|
| **P0** | 「可产品化口径」的样本量：生产链路输出 **K̂ ≤ 2** 的场次数 | **≥ 5** | 若不足 ⇒ **`inconclusive`**，且**"生产链路极少输出 K̂≤2"本身就是结论**（不是失败） |

> ⚠️ **P0 的诚实说明（防"空手而归"）**：P0 与 P1/P2 都依赖**跑完才知道的 K̂**，
> 故存在"样本不足 ⇒ 只得到 inconclusive"的可能。**这是刻意的**——
> 按 K̂ 分档是**唯一可产品化**的口径，若产品认不出该档，**判据再漂亮也拿不到**。
> ⇒ 若 P0 不达标，**本轮仍产出两个有用的量**：**D1**（真值档是否达标）与
> **K̂ 分布**（产品能否识别该档），二者共同回答"这条路径是否可产品化"。
> **不得**为了让 P0 达标而改用"真值档"替代 P1/P2。

### 1.2 主判据（**可产品化口径**：按**生产输出 K̂ ≤ 2** 分档）

产品**能事先观察到的只有 K̂**（不是真值）——故只有按 K̂ 分档才可产品化。

| # | 条件 | 门槛（**沿用既有英文线**） |
|---|---|---|
| **P1** | K̂ ≤ 2 场次上 **DER 均值** | ≤ 0.40 |
| **P2** | K̂ ≤ 2 场次上 **DER 最差场** | ≤ 0.60 |

### 1.3 诊断判据（**按真值 K_true ≤ 2** 分档，仅用于对照，**不得当产品依据**）

| # | 条件 | 门槛 |
|---|---|---|
| **D1** | K_true ≤ 2 场次上 DER 均值 ≤0.40 且最差场 ≤0.60 | 同门限 |
| **D2** | **P1/P2 与 D1 的差**（"分档是否可产品化"的直接度量） | **必报**（无门槛，是读数） |

> **D2 为什么关键**：若 K_true≤2 达标而 K̂≤2 不达标（样本量也不足），说明
> **产品无法识别"这是低人数素材"** ⇒ 该档达标也**拿不到**。这与 ADR-0006 的
> **(a) 表达能力欠账**（结构性无法输出 K=1）是同一件事的另一种表现。

### 1.4 反平凡性

| # | 条件 | 门槛 |
|---|---|---|
| **R1** | 若 P1/P2 达标：K̂≤2 组的 DER **分布不得全部 < 0.05** | 至少 1 场 ≥0.05（否则素材过易，结论无区分力） |
| **R2** | 必须同时报 **均值与最差场** | 禁止只报其一 |

### 1.5 判定规则（**先写死**）

| P0 | P1 | P2 | 判定 | 后续 |
|---|---|---|---|---|
| ❌ | — | — | **inconclusive**（K̂≤2 样本不足） | **"分档不可产品化"成立** ⇒ 该路径关闭；转 D1 诊断结论 |
| ✅ | ✅ | ✅ | **主场景达标（可产品化）** | 可讨论 D3 标注**按 K̂ 分档**（须另立门，且**不得**变成"部分可用"软约束） |
| ✅ | 任一 ❌ | | **主场景不达标** | 多机位线在主场景亦无可用路径 ⇒ 建议冻结 |

## 2. 数据与方法（**冻结**）

| 项 | 冻结值 |
|---|---|
| 语料 | VoxConverse test **未读**（与 P115/P117/P127 及 P134 已读集合**取差**后） |
| 场次集 | `K_true ≤ 2 且时长 ≥120s` ⇒ **28 场**（K_true=1: 14 场；K_true=2: 14 场） |
| 清单 | `unread-lowk-manifest.json`（**先于跑数生成**；已 grep 抽查既有 `evidence/`+`docs/` **0 命中**） |
| 链路 | **生产链路** `SpeakerDiarizationService.analyze_path`（真实 ffmpeg + Silero + CAM++） |
| 判据输入 | **生产落库的 `speaker_count`（K̂）与 DER**，**不用 oracle K** |
| 时长口径 | `ffprobe format=duration`（与既有 diag 逐场 0.00 差，已核） |
| DER 口径 | `tools/quality_eval/diarization.score`，**`ignore_overlap=True`**（门 §5 声明口径） |
| 报告 | **逐场**读数 + 分组汇总；**禁止只报汇总** |

**为什么选 VoxConverse**：其为 YouTube **真实双人/多人对话**（in the wild），
采集条件比 AMI 近场头戴会议**更接近**口播/对谈产品场景；
但 DER 绝对值**不可**与 AMI/AISHELL-4 比大小（P115 已声明）。

## 3. 必须报的负向对照

| # | 对照 | 预期 |
|---|---|---|
| **NC1** | **K̂ 的分布**（全 28 场） | 若无一场 K̂≤2 ⇒ P0 自动 inconclusive（**必须如实报**，不得跳过） |
| **NC2** | **随机标签**的 DER（每场随机分 K_true 份） | 必须**明显差于**生产输出（否则 DER 实现可疑） |
| **NC3** | **oracle 天花板**（每窗直给主导真说话人） | 给出该档上界，用于判断差距性质 |
| **NC4** | 只报达标档不报其他 | **禁止**——须同报 K_true=1 / K_true=2 两档 |

## 4. 不判的事（边界）

- **不判**精度门整体（门限表是**双语料**的判定；本轮只问**一个场景档**）；
- **不判**任何候选的采用；
- **不判**中文侧（本机另有未读 K≥3 32 场，不在本轮）；
- **不判**生产耗时（另有一次读数可顺带报）；
- **不判** W2.3 接线。

## 5. 污染声明（**必须与结论同读**）

- **本 28 场为首次读取**（已 grep 证明既有 `evidence/`+`docs/` 0 命中）；
- 但 VoxConverse **语料本身**已被 P115/P117/P127/P134 读过 ⇒
  结论**仅限于这 28 场**，**不得**外推为"VoxConverse 低人数档整体如此"；
- **不得**声称发现新机制；**不得**据以宣告精度门已过；
- 允许的结论强度：**"在这 28 场（首次读取）上，K̂≤2 样本量 = N，其 DER 为 X/Y"**。

## 6. 若达标，允许做什么、禁止做什么（**先写死，防回潮**）

**允许**：另立门讨论"按 **K̂** 分档标注"（`quality_status` 分档），
但该门**必须**证明分档判据**只依赖产品可见量**（K̂），**且**该分档在**未读语料**上验证过。

**禁止**（门 §2 已冻结的硬约束，本轮不得松动）：
- **不得**变成"同一场素材内只交付高置信区间"（§5.21 已否决——无判据且最差场更差）；
- **不得**引入任何**需要真值/人工**的分档；
- **不得**以本实验结论替代 **S3**（那需两语料全量重跑）。

零迁移 / 零契约 / 零 egress / **不改生产代码**（只调用生产服务 + 纯函数）。

## 1. 右侧属性面板重构规范（对齐剪映）

### 1.1 信息架构（IA）

- **视频 / 图片片段**（图片片段无「音频」页签）：
  - 顶层页签：`画面 | 音频 | 变速 | 动画`
  - `画面`：`基础`（缩放、等比开关、位置 X/Y、旋转、不透明度、画面布局三选一、折叠「更多画面能力」占位）、`抠像`（启用、键色、相似度、边缘平滑、反选、清除）、`蒙版`（无/线性/矩形/椭圆、几何参数、羽化、反选、清除）
  - `音频`：`基础`（启用音频、音量 dB、源修剪、淡入/淡出时长、响度归一）、`换音色`【占位】、`声音效果`【占位】
  - `变速`：倍速预设 + 自定义 `0.25–4.0` + 倒放（仅视频，权威预览生效）
  - `动画`：位置 / 缩放 / 旋转 / 透明度关键帧打点
- **音频素材 `A1`**：顶层页签 `基础 | 换音色【占位】 | 声音效果【占位】 | 变速`
- **文本 / 字幕 `C1`**：顶层页签 `文本`（`基础`：文本、字体、字号、B/U/I、颜色、描边、字/行间距、对齐、预设、时间/边距；`气泡` / `花字`）| `动画【占位】`

### 1.2 字段映射（UI → Contracts → 渲染）

| UI 控件 | contracts 字段 / patch op | 渲染 |
|---|---|---|
| 缩放 / 位置 / 旋转 / 不透明度 | `transform.{scale,x,y,rotate,opacity}` ← `set_clip_transform` | 统一盒模型 overlay |
| 画面布局 | `layout` ← `set_layout` | `_visual_filter` |
| 倒放 | `reverse_playback` ← `set_reverse_playback` | reverse 分支 |
| 抠像 | `keying.{color,similarity,blend,invert}` ← `set_clip_keying` | `rgba-geq` / 着色器 |
| 蒙版 | `mask.{kind,x,y,width,height,rotation,feather,invert}` ← `set_clip_mask` | `rgba-geq` / 着色器 |
| 音频 / 淡入淡出 | `audio.{enabled,gain_db,fade_in_us,fade_out_us}` ← `set_audio` | 音频混流 + `afade` |
| 源修剪 / 倍速 / 关键帧 | `trim_clip` / `set_speed` / `set_clip_keyframes` | Core 管线 |
| 文本 / 时间 / 样式 | `update_caption` / `set_caption_timing` / `set_caption_style` | ASS 渲染 |

### 1.3 占位、画布交互与视觉规范

- **占位规范**：统一琥珀色描边徽章 `规划中`，控件 `opacity: .45 + pointer-events: none`，页签保持可见以呈现完整能力版图。
- **画布拖拽守则**：蒙版/PiP 拖拽一律使用**增量位移**（`pos = pos0 + Δpointer`，锚定抓取点相对盒中心偏移），禁止用指针绝对位置反推中心以防向左上跳动；数值步进器同时支持箭头点击、左右搓值（`ew-resize`）与键盘 `↑↓`。
- **抠像与蒙版画布示意**：12px 双色棋盘格示意抠像透明区；蒙版显示 1.5px 虚线边界与微光晕（反选转红），交互预览同步实时裁剪。
- **面板视觉度量（336px 宽）**：
  - 表面 `#12171c` / 面板 `#161c22` / 内嵌控件 `#0e1318` / 分隔 `#1f2931` / 描边 `#263038/#33404a`；
  - 强调 `#86a0ff → #5b78f0`，琥珀 `#d9b36a`，绿 `#57cf92`；
  - 顶层页签高 44px、子页签胶囊 32px、行高 32px（标签列宽 56px）、数字步进器高 28px、滑杆 3px 轨道 + 13px 拇指、开关 `32×18`、分段选择高 30px。

## 2. Graphite Precision 弹窗视觉系统 v2 规范

> 视觉方向定为 **Graphite Precision**（冷石墨层级、清晰边缘、薄荷青 `#35d6ae` 有限语义强调）；`apps/desktop/tests/fixtures/dialog-system-v2/` 保留用于 CSS 保真回归的静态 HTML 基准稿（`index.html` 与 B/C/D 族结构稿）。

### 2.1 代表场景与宽度档位

| 档位 | 名义宽度 | 用途与代表弹窗 |
|---|---:|---|
| 紧凑 | `440px` | 短确认、不可逆破坏性操作（如删除素材，取消先于危险操作） |
| 标准 | `640px` | 导出视频、Provider 设置、命令搜索、纯表单与列表型弹窗 |
| 工作台 | `860px` | 双栏参数与时间线预览（剪辑手法、生图/工作台），`900px` 以下退化单栏 |

实现统一以 `min(名义宽度, 可用宽度)` 约束，外周留白 16–22px；单操作弹窗（如导出）不虚构取消按钮；命令搜索无业务主按钮。

### 2.4 统一解剖结构与五族结构契约

- **四段式骨架**：标题区（`21px 24px 18px`，小屏收紧 `17px 24px 14px`）→ 可选页签/上下文条 → 唯一主滚动内容区（水平 `24px`、底部 `22px`）→ 固定底栏（最小高度 `65px`，全局唯一主级动作固定右下，取消在主操作之前）。
- **五个弹窗解剖族**（覆盖全部业务弹窗）：
  - **A 纯表单族**：`fieldset` 分组、无分栏（复用 Provider 稿）。
  - **B 步骤流族（`prototype-step-family.html`）**：严格区分 `.step-progress`（进行中 4px 进度条）、`.step-list`（结果态三列 `28px minmax(0,1fr) auto`，行高 `65px`，徽章随状态变色）与 `.step-bar`（流程阶段指示）。
  - **C 列表型族（`prototype-list-family.html`）**：固定检索+行列表（行高 63）、数据表格（表头 10.5px、右对齐 + `tabular-nums`）与状态行+表单三种形态；空态/加载/错误占相同高度防跳变。
  - **D 三步确认族（`prototype-egress-confirm-family.html`）**：外传确认五段固定顺序（① 发什么 `.egress` 限高 180px → ② 发给谁 → ③ 花多少 → ④ 凭什么可信 → ⑤ 勾选框紧贴预览 + 底栏 danger 主按钮）。
  - **E 双栏工作台族**：页签 + 左参数 + 右预览（复用剪辑手法稿）。
- **验证方法**：除单点数值断言外，关键族需配套元素对齐关系断言与改前改后逐元素计算样式校验。

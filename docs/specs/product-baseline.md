# 产品基线与核心编辑能力标准

> 本文定义 Vortex Cut 的产品定位与基础编辑能力验收基线（原 A1–A4 / B1–B4 / C1–C4 标准）；当前各工作线的最新交付状态、未闭环承诺与已交付能力边界统一见 [`../STATUS.md`](../STATUS.md)（Rule 1 / Rule 5）。

---

## 1. 产品定位与设计约束

Vortex Cut 定位于 **AI 驱动、人机共享** 的视频创作工具。所有核心设计遵循以下产品约束：

- **程序化对等**：所有核心 UI 操作必须有对应的可序列化 Command 或 Core API，供 AI Agent 与外部调用方复用（参见 `AGENTS.md` Editor Command Layer Discipline）。
- **状态可追踪**：所有时间线与项目状态变更必须落入版本化 Revision 账本，可追踪、可回放、可撤销。
- **人机双轨兼顾**：界面交互兼顾创作者直觉，底层数据结构与操作协议兼顾机器可调用性与确定性校验。

---

## 2. 核心编辑能力标准（A1–A4 / B1–B4 / C1–C4）

> 以下编号（A1–C4）为多份设计文档与验收回归锁的长期基准标识，保持编号稳定。具体模块设计与渲染契约见 [`timeline-and-editing.md`](timeline-and-editing.md) 与 [`preview-and-rendering.md`](preview-and-rendering.md)。

### 阶段 A：基础交互与时间线骨架

#### A1. 时间线多轨道渲染引擎
- 支持至少 3 条视频轨道 + 3 条音频轨道（并可扩展动态视频/文本轨）的可视化渲染。
- 支持片段在轨道间拖拽移动，拖拽时有辅助线/高亮指示目标位置。
- 支持自动吸附到相邻片段边界或播放头（吸附距离 ≤ 10px）。
- **验收**：拖拽片段到任意合法轨道，位置正确，吸附生效，预览随之更新。

#### A2. 素材箱与预览联动
- 素材箱支持缩略图视图和列表视图切换。
- 双击素材在预览窗口播放（仅播放，不自动添加到时间线）。
- 从素材箱拖拽素材到时间线，自动生成片段，长度与素材一致。
- **验收**：拖拽到时间线后片段出现，预览播放正常。

#### A3. 基础剪辑操作
- **分割（Split）**：在播放头位置将片段一分为二。
- **修剪（Trim）**：从片段开头或结尾拖拽裁剪，保留中间部分。
- **删除**：选中后按 `Delete`/`Backspace` 移除。
- **复制/粘贴**：支持 `Ctrl+C`/`Ctrl+V`，粘贴位置在播放头或鼠标位置。
- **验收**：所有操作即时生效，预览同步，时间线显示正确。

#### A4. 撤销/重做（编辑操作覆盖）
- 覆盖 A3 中所有编辑操作（分割、修剪、删除、复制粘贴）及高级编辑操作。
- 撤销/重做支持至少 50 步历史回溯（基于不可变 Revision 历史）。
- **验收**：任意操作后撤销 5 步，时间线逐步恢复；重做 5 步，逐步重做。

---

### 阶段 B：高级编辑能力

#### B1. 片段变速与反向播放
- 片段速度预设：`0.25x`、`0.5x`、`0.75x`、`1x`、`1.25x`、`1.5x`、`2x`、`4x`。
- 支持自定义速度值（输入框）。
- 支持反向播放（倒放）开关。
- **验收**：变速后音视频同步（音频变调或保持音高至少实现一种），预览播放正常；倒放效果正确。

#### B2. 转场系统
- 实现至少 5 种转场（当前已冻结 8 种 FFmpeg `xfade` 类型：淡入淡出/经黑淡出、滑动、缩放、擦除、溶解）。
- 转场可置于同轨相邻视频/图片片段之间，时长可调（默认 `0.5s`，范围 `0.1s–2s`）。
- 转场在权威预览与导出中正确渲染，不影响相邻片段外侧内容。
- **验收**：时间线显示转场标记，权威预览播放转场效果正确。

#### B3. 关键帧动画
- 支持在时间线上为片段添加关键帧（位置、缩放、旋转、透明度四属性）。
- 关键帧在时间线上可视化显示并可拖拽调整。
- 播放时属性在关键帧间线性插值过渡。
- **验收**：添加关键帧后权威预览动画流畅，调整关键帧位置后动画相应变化。

#### B4. 字幕与文字叠加
- 独立文字/字幕轨道支持添加多个文字片段。
- 文字样式可编辑：注册字体、字号、颜色、描边（宽度 + 颜色）、位置（预设顶部/居中/底部 + 自定义坐标）、气泡与花字预设。
- 文字片段时长可拖拽调整。
- **验收**：添加文字后预览显示正确样式，调整样式即时更新。

---

### 阶段 C：交互打磨与反馈

#### C1. 播放头与时间线导航
- 播放头可拖拽，松开后预览跳转到对应帧。
- 时间线标尺显示时间刻度（秒/帧），随缩放级别变化。
- 左右方向键逐帧步进（1 帧/步），`Shift+方向键`步进 5 帧。
- **验收**：拖拽播放头预览同步，逐帧步进画面逐帧变化。

#### C2. 任务进度与反馈
- 所有长时间任务（代理生成、导出、AI 处理）显示进度条 + 剩余时间估计。
- 估计基于已处理速度和总工作量动态计算。
- 任务可取消，取消后清理临时文件。
- **验收**：长时间任务进度持续更新，取消后无残留临时文件。

#### C3. 快捷键系统
- 默认快捷键：分割 `S`、删除 `Delete`/`Backspace`、复制 `Ctrl+C`、粘贴 `Ctrl+V`、撤销 `Ctrl+Z`、重做 `Ctrl+Y`、播放/暂停 `Space`、放大时间线 `Ctrl+=`、缩小时间线 `Ctrl+-`、适配时间线 `Ctrl+0`。
- 提供快捷键设置面板，支持自定义键位。
- **验收**：快捷键响应正确，设置面板修改后立即生效。

#### C4. 时间线缩放与滚动
- 时间线支持水平方向放大/缩小轨道视图，并在轨道溢出时支持纵向滚动。
- 滚动条或滚轮浏览时间线（`Ctrl+滚轮`以光标为锚缩放，普通滚轮滚动）。
- **验收**：缩放后片段显示精度变化，滚动流畅。

---

## 3. 程序化与可审计契约原则

- 所有新增编辑能力必须先在 `apps/desktop/src/app/commands/` 定义入参/出参纯 JSON 可序列化的 `CommandDefinition`，并映射到底层确定性 `TimelinePatch` 操作。
- 时间线状态变更产生可审计的不可变 Revision 记录与结构化 Diff，供人工核对与 AI Agent 感知状态变化。

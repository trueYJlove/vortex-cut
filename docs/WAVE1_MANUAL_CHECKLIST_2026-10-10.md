## A. 去停顿（remove_pauses）

- [ ] 素材箱选中口播视频 →「剪辑手法」→ 去停顿页：参数默认 0.05 / 400ms / 50ms，时间轴示意随滑杆实时变化。
- [ ] 该素材已做「AI 信号分析」→ 干跑出摘要与操作数；未分析 → 明确报错文案（引导先分析），不是静默。
- [ ] 生成提案 → Diff 正确 → 采纳后时间线闭合、预览无停顿段。
- [ ] 空操作（无静音）时采纳按钮禁用。

## B. 卡点（beat_sync）—— L2 新链路

- [ ] 选 BGM/音频轨片段 + 勾选镜头段 → 「节拍网格」行显示「无节拍网格」并出现**「分析节拍」按钮**。
- [ ] 点击「分析节拍」→ 状态变「分析中…」→ 数秒后自动变「✓ 已就绪 · BPM … · N 拍（强拍 M）」，按钮收起。
- [ ] 就绪后干跑 → 卡点摘要非空（镜头吸附 beat）；生成提案 → 采纳 → 切点落在节拍上（播放听感对拍）。
- [ ] 换一个无音轨素材做 BGM → 分析后显示「无法检出节拍」且可重试，不报错横幅。
- [ ] 素材文件被外部修改后再进面板 → 显示「素材已变化，需重新分析」。

## C. L/J cut（lj_cut）—— L1 词戳链路

- [ ] 对口播素材先转录（词级）→ 面板 L/J 页「词戳来源」显示 **「ASR 词级转录 ✓ —— Core 自动拉取」**。
- [ ] 未转录的素材 → 显示「无词级转录 —— 先在转录页转录」；干跑报「缺少词级时间戳」文案引导，不静默。
- [ ] mode=自动：切点后有词走 J（声先入）、无下句词走 L；手动 J/L 各试一次。
- [ ] 生成提案 → 采纳 → 预览听感：J 提前 300–500ms 入声 / L 延后。

## D. 通用

- [ ] 提案基线漂移（采纳前在外部改动时间线）→ 面板提示基线已变化并禁用采纳。
- [ ] 历史提案可打开查看；已采纳的不可重复采纳。
- [ ] 三页全部零 egress（无网络活动提示/无 Provider 面板弹出）。

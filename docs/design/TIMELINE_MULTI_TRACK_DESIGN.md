# M2 — 剪映式多轨道时间线设计说明

状态：已实现（结构、UI、校验、渲染保护与端到端测试）
前置：`FREE_POSITIONING_DESIGN.md`（V1 轨内自由定位）；本文把时间线升级为多轨道结构。

## 1. 轨道结构（对齐剪映）

tracks 数组顺序 = 界面自上而下：

```
[ 动态视频轨 V2+ / 动态文本轨 T1+ ]   ← 可任意添加、删除、交换位置
C1  字幕轨（text）                    ┐
V1  主视频轨（video）                 ├ 三条固定轨：恒存在、相对位置固定
A1  音频轨（audio）                   ┘
```

- 固定轨不可删除、不可移动；动态轨只能在 C1 之上的区域内换位。
- 轨道对象：`{ id, kind: "video"|"text"|"audio", locked, hidden, muted, solo }`。
- 旧文档自动迁移：kind `visual→video`、`caption→text`，补齐标志位与缺失的 A1，顺序规范化（`_normalize_tracks`）。

## 2. 片段与轨道

- 视觉片段（video/image）可在任意视频轨；音频片段固定 A1；片段与轨道类型不匹配即拒绝。
- 同轨不重叠（允许空隙）不变；**跨轨叠加允许**（上层轨盖住下层）。
- `position_clip` 支持可选 `track_id`（跨同类型轨道移动）；`insert_asset_clip` 支持可选 `track_id`（投放目标轨，默认主轨）。
- 转场仍仅限主轨 V1 首尾相接的相邻片段。

## 3. 新增 patch 操作

| op | 说明 |
| --- | --- |
| `add_track {kind: "video"|"text"}` | 新建 V2+/T1+，插入到 C1 之上（动态区底部） |
| `remove_track {track_id}` | 删除动态轨；其上片段与绑定字幕级联删除（固定轨拒绝） |
| `move_track {track_id, to_index}` | 动态区内换位（结构性操作，锁定轨也允许） |
| `set_track_flags {track_id, locked?, hidden?, muted?, solo?}` | 部分覆盖；hidden 仅视频/文本，muted/solo 仅视频/音频 |

轨道锁定：保护片段内容——锁定轨上的片段操作与投放/删除被拒（`TIMELINE_LOCKED`）；解锁与换位不受限。AI Patch 禁用全部轨道结构操作。

## 4. 渲染与预览

- plan 段落携带 `track_id` / `track_hidden`；轨道静音/独奏合并进 `audio_enabled`（`muted → 无声`；存在 `solo` 轨时仅独奏轨出声）。
- 渲染图当前为"主轨单视觉轨"语义：只装配 V1 可见片段（空隙黑底、休眠转场跳过）；主轨隐藏/为空时输出全程黑场（时长取全部片段最大终点）。**覆盖轨合成（overlay）与 A1 混音为后续工作。**
- 交互预览取播放头所在**最上层可见**视频轨片段；轨道静音/独奏作用于预览音频。

## 5. 桌面端 UI

- **轨道属性头（左栏，每轨一行）**：`[类型标识 V2/T1/A1] [锁定] [隐藏(视频/文本)] [静音(视频/音频)] [独奏(视频/音频)]`；悬停动态轨头部出现 `↑ ↓ 删除`。
- **添加轨道**：标尺左上角 "＋" 按钮 → 视频轨道 / 文本轨道。
- **轨道行**：画布按 tracks 数组自上而下绘制，行高随轨道数自适应压缩（全部轨道保持可见）；隐藏轨片段以 35% 透明度显示。
- **播放头（剪映式）**：全高白色细线 + 顶部圆角手柄；标尺可拖，**鼠标不在素材上时按住任意空白位置即可拖动播放头**；Shift+拖拽保留框选。
- **跨轨拖动**：拖动片段时按指针所在行切换目标轨（同类型），落点按目标轨钳制不重叠。

## 7. 已知限制

- 覆盖轨内容不参与成片渲染（多轨 overlay 合成为后续工作）；交互预览为"最上层可见片段"近似。
- A1 音频混音仍未实现（同前）。
- 轨道数超过可视高度时行高压缩至 30px 下限，极端数量需要纵向滚动（未实现）。

## 8. 剪映对齐细节（第二轮）

- **滚轮策略**：`Ctrl+滚轮` = 以光标为锚缩放；普通滚轮 = 滚动时间线区域（纵向溢出时原生纵向滚动，否则横向平移）；Shift/触摸板横向 = 横向平移。缩放不再与区域滚动冲突。
- **行高固定**：轨道行高固定（默认 56px），不随窗口大小压缩；轨道过多时时间线区域纵向滚动（左栏与画布同步伸展）。
- **标尺**：高度 20px（贴近剪映比例）。
- **轨道头开关按需显示**：轨道上没有素材时只显示类型标识，锁定/隐藏/静音/独奏在拖入素材后才出现（动态轨的 ↑↓删除 仍常驻悬停显示）。
- **视频帧缩略图**：视频片段按宽度抽帧（共享隐藏 `<video>` 池 seek 抽帧，绘制进画布），胶片帧铺满片段主体；图片素材直接用原图。
- **拖拽跟随**：单片段拖动时片段本体实时绘制在目标位置（跟随鼠标），原位置腾空，仅保留时间提示浮层；组移动仍为半透明 ghost。
- **添加轨道入口**：时间线工具栏最左（撤销按钮左侧）"＋"按钮 → 视频轨道 / 文本轨道。
- **显示设置（工具栏最右"…"）**：轨道高度滑杆（40-96px）+ 波形占比三档（100%/60%/30%），与磁吸开关一并持久化（`vortex-cut.timeline.prefs.v1`）。波形靠片段底边绘制，占比即其高度比例。

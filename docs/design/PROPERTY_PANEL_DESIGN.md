## 0. 背景：先回答「蒙版对不对」

**语义层面是一致的，不需要推翻**：

- 剪映：V2 片段蒙版 = 只显示区域内画面，区域外透出下层（V1）；V2 天然盖在 V1 上。
- 本项目：`TimelineClip.mask` 走 FFmpeg `geq + alphamerge`，最终 alpha 与抠像相乘后叠加到主画面 —— 语义相同，成片/权威预览里 V2 已在 V1 上方。

**差异在呈现，不是模型**：

1. 交互预览画布此前**不渲染**蒙版/抠像效果（只有权威预览/成片可见），用户在画布上看不到变化，感觉"没生效/不一样"。
2. 属性面板是**平铺长列表**（蒙版下拉、抠像开关、变换、关键帧全堆在一列），不像剪映按「画面 → 抠像 / 蒙版」分页签组织，功能可发现性差。

本设计同时修这两点：面板按剪映 IA 重构 + 画布补蒙版边界交互。

## 3. 字段映射（UI → contracts → 渲染）

| UI 控件 | contracts 字段 / patch op | 渲染 |
| --- | --- | --- |
| 缩放 / 位置 X / Y / 旋转 / 不透明度 | `transform.{scale,x,y,rotate,opacity}` ← `set_clip_transform` | PIP overlay 链（中心点语义） |
| 布局 三选一 | `layout` ← `set_layout` | `_visual_filter` |
| 倒放 | `reverse_playback` ← `set_reverse_playback` | reverse 分支 |
| 抠像：启用/键色/强度/边缘平滑/反选 | `keying.{color,similarity,blend,invert}` ← `set_clip_keying` | colorkey + alphaextract |
| 蒙版：类型/几何/羽化/反选 | `mask.{kind,x,y,width,height,rotation,feather,invert}` ← `set_clip_mask` | geq + alphamerge |

- 统一徽章：`规划中`（琥珀色描边），子页签下加 `规划中` 小字。

## 5. 画布交互补齐（配合面板）

1. **蒙版边界可视化（本设计新增）**：画布上显示蒙版虚线边界（椭圆/矩形框、线性分界线），可拖框体平移、拖白色把手缩放——即 `mask-canvas.html` 原型已验证的交互，落到真实画布。反选时边界变红示意。
2. **抠像预览策略**：色度键属逐像素计算，交互画布用**棋盘格示意**"已抠透明"，精确边缘以权威预览/成片为准；面板内加提示文案。
3. **V2 叠序**：交互预览已把 V2 片段渲染在 V1 上方（`PreviewPipOverlays`）；成片侧 `_pip_overlay_chain` 同语义。原型 video.html 左侧即此效果的演示。
4. **滑杆提交语义（沿用现状）**：拖动 = 本地 draft（不落 Revision），`pointerup`/`blur` 提交单条 patch，可撤销。
5. **拖拽实现守则（防"不跟手"）**：画布拖拽一律用**增量位移**（`pos = pos0 + Δpointer`，锚定抓取点相对盒子中心的偏移），**禁止**用指针绝对位置反推中心/左上角——盒子以中心点定位时，绝对反推会让第一次 move 就把中心吸附到指针处（向左上跳）。数值步进器同样提供三种操作路径：点击箭头（≥17×12px 命中区）、按住数值左右拖动搓值（ew-resize 光标）、键盘 ↑↓。

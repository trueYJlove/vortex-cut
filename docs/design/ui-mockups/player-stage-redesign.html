E2 · 音效动画（VU 电平表）—— 让"没效果"变成有动画

时间码右侧的音量动画必须真实可见：播放时两条细条随电平跳动，静止时回落。

00:00:03:12 / 00:00:15:00
播放时跳动 静止回落 30%
  • 动画来源：音量 ≠ 静音时必须真实驱动 —— 用 WebAudio 分析当前播放媒体（或媒体元素 volume 模拟），两条 2.5×12px 细条按实时电平 30% → 100% 跳动、白色；彻底杜绝"点了播放却一动不动"。
  • 静止态：#3A3F4C 30% 高度，明确可辨（不是透明/不可见）。
  • 与时间码间距：8px，flex 排列，永不重叠。
  • 实现要点：沿用现有 vuBarLRef/vuBarRRef 与 VU 轮询；把 12% 基线 提为 30% 基线、动画范围 30–100%，且播放中每帧都更新（当前实现可能因 AudioContext 采样为空而静止 —— 增加"无真实音频时用音量值模拟跳动"的回退，保证永远有动画）。

05时间线 · 最终设计（冻结标尺 + 0 刻度对齐片段区 + 主轨封面入口）

结构：标尺带 16px 恒定，位于滚动区外（Excel 冻结表头式）——滚动轨道、拖拽下方手柄调整面板高度， 标尺都纹丝不动；滚动区 = 轨道头列(120) + 封面条带(120，随轨道滚动) + 片段区，0 刻度对齐片段区起点。 封面入口照剪映通用做法：仅主轨 V1 一处，点击截取当前播放头画面设为封面。 片段/标尺/波形由真实绘制代码渲染（搬自 drawTimeline：取色、字体、形状与软件一致）—— 可交互：悬停标尺看时间、点击/拖动定位播放头、双击标尺适配内容、拖拽底部手柄改变面板高度。

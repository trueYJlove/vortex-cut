# 性能第一轮 A01–A08 汇总

> **历史实施摘要（2026-09-08 至 2026-09-09）**。详细目标与方案见[性能实施计划](PERFORMANCE_IMPLEMENTATION_PLAN_2026-09-08.md)；统一复测与验收证据见[ G1 复测报告](PERFORMANCE_G1_RETEST_2026-09-09.md)。本文合并原 A01–A08 八份实施自检稿，不声明当前性能状态。

## 实施内容

| 包 | 合并后的结论 |
|---|---|
| A01 生命周期 | 统一预览 Worker 握手超时与取消路径；创建失败、卸载和项目切换统一释放资源；迟到帧只释放、不回调旧组件。 |
| A02 音频缓存 | session 级 single-flight 音频加载，最多两个并发；播放时只预热当前与近邻片段；暂停时不预热；替换 IR 时同步更新音源。未引入 B15 流式引擎。 |
| A03 解码索引 | 构建 PTS 排序索引和关键帧索引，以二分查找替代逐样本扫描；顺播局部推进上限 64 步，超限回到二分查找；保持既有送包与帧所有权语义。 |
| A04 IR 扫线 | 主轨、覆盖轨和字幕改用区间扫线索引；预映射转场锚点，并为画中画手势建立 clip 索引。900 段/900 字幕同机中位数由约 2701ms 降至约 189ms；G1 复测为约 173ms，输出 JSON 与基线逐字节一致。 |
| A05 Core 后台工作 | 哈希工作移出事件循环，加入取消令牌与前后 stat 校验；IR 投影 single-flight 并后台执行。进程池保留为显式实验选项，默认关闭。 |
| A06 画布失效 | 播放头移至独立 DOM 层，播放时主画布不随播放头重绘；canvas backing size 仅在变化时赋值；用户 seek 有独立请求 ID。 |
| A07 探测缓存 | 按素材指纹、文件 stat 和 ffprobe build 缓存探测结果；编码器能力检测按 session 缓存，渲染失败可清除对应 smoke 缓存。 |
| A08 请求调度 | 轮询改为前一轮结束后再排下一轮；转录正文按需加载；缩略图 loader 加入可取消视口代次、优先级和有界清理。 |

## 验收与限制

- G1 复测报告逐项核对 A01–A08；桌面 56 文件/467 项、Core 489 项通过，F01 回归通过，F02 900 段/900 字幕复测约 173ms。
- 原实施自检均注明“独立验收待验收”；G1 报告也明确这是开发者自测口径，不等同独立 Gate。统一复测结论以 G1 报告为准。
- A02 真机长测/听感、A03 真机 seek 延迟、F03–F07 完整场景与正式重复采样等限制见 G1 报告；本摘要不把未执行的测量表述为通过。

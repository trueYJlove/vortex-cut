## 2. 勘误（已随本记录落实）

- E1：非字幕帧 PSNR 实测范围应为 **19.10–35.36dB（min@n=510）**，报告 §0/§2.3 与 ADR §1/§3-3 中"15.1–35.4（min n=1590）"的表述有误（n=1590 实为字幕帧）；≥19dB 门成立且恰以实测下限为基；
- E2：无 PiP/慢速帧桶参考值实测 min 30.99dB（n=1799），报告"31.2–35.4"与 ADR"≥31dB"参考值已改为 31.0/≈31（参考值非绑定门）；
- E3：position 关键帧缺陷的冻结尾部措辞改为"内容 [45,60s)，其后 [60,106s) 为冻结帧（相对时间线末超长 45s）"；
- E4：P3 目标集构成注明 proxy 材质因 stss 全关键帧实际为 100 uniform（while 补齐）。

# 浅色主题缺口修复（2026-11-10 · Round 14）

## 发现的问题
主题切换在上一轮只覆盖了 DOM 元素，**时间线画布没跟随**：
画布用 `ctx.fillStyle` 绘制，不吃 CSS 选择器，颜色是硬编码常量。
结果：浅色主题下，面板与弹窗都变浅，时间线仍是一整块深色。

## 修复

### 1. 画布颜色改为从 CSS 变量读取
`TimelineCanvas.tsx` 新增 `cssColor(name, fallback)`：读 `documentElement`
上的计算值，取不到时回退原深色常量（保证测试/离屏渲染不依赖样式表）。
涉及的变量：`--tl-ruler-top/bottom`、`--tl-dead-bg`、`--tl-row`、`--tl-row-audio`。
深色值即原硬编码常量，**深色视觉零变化**。

### 2. 主题切换强制画布重绘
`MutationObserver` 监听 `<html data-theme>`，变化时 `setThemeEpoch` 自增，
并把它加进两处绘制 effect 的依赖数组。
（只改变量不够——不重绘的话画布仍是旧填充色。）

### 3. 新功能的硬编码色改令牌
区间角标与清除按钮原用 `rgba(12,20,18,.92)`，浅色下会是一块黑斑；
改为 `var(--dlg-raise)` / `var(--ws-accent-line)`。

## 踩到的级联陷阱（本轮最花时间的地方）

`dialog-graphite-style.test.ts` 断言深色 `--dlg-*` 令牌的**最后一次定义**
必须在文件最后 20% 内（防止历史块反超）。三条约束互相拉扯：

| 放法 | 测试 | 浅色是否生效 |
|---|---|---|
| 追加到文件末尾 | ❌ 红（lastIndexOf 命中浅色值） | ✅ |
| 移到「令牌终值」块之前 | ✅ 绿 | ❌ 失效（:root 在后面反超） |
| **`html[data-theme="light"]` + 放在终值块之前** | ✅ 绿 | ✅ |

最终解法：把浅色覆盖放在终值块之前，但选择器从 `[data-theme="light"]`
提升为 `html[data-theme="light"]`（特异性 0,1,1 > `:root` 的 0,1,0），
既能压过终值块，又不占文件末尾的 20% 判据。

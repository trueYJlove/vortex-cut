# Vortex Cut 用户使用手册

> 版本：0.0.1  
> 适用对象：第一次使用 Vortex Cut 的普通用户  
> 适用范围：本地视频剪辑、素材管理、本地转录、字幕编辑、预览与导出  
> 当前文档状态：面向桌面端实现的操作说明；**2026-11 桌面界面已推进 OpenFilm 风格视觉与交互重构（`P225–P235`），第 4 节早期界面分区描述正在随新 UI 同步更新。最新已交付能力边界统一见 [`../STATUS.md`](../STATUS.md) §3。**

## 1. 你可以用 Vortex Cut 做什么

Vortex Cut 是一个本地优先的视频剪辑工具。当前版本可以完成一条基础的视频制作流程：

1. 创建项目；
2. 导入视频、音频或图片素材；
3. 将视频或图片加入时间线；
4. 调整片段顺序、起止时间、布局和音频；
5. 使用本地转录生成字幕素材；
6. 选择转录片段加入时间线并自动生成字幕；
7. 在时间线中修改字幕内容、时间和样式；
8. 生成权威预览；
9. 导出最终视频。

当前版本还提供以下可选能力：

- 多平台画幅预览与批量导出；
- 静态焦点重构与批量导出；
- AI 粗剪候选方案；
- AI 修改提案；
- 镜头与资产需求清单；
- 模拟生成验证。

其中 AI Provider 相关功能属于受控高级功能，可能把明确选择的内容发送到外部服务。第一次使用时，可以完全不使用这些功能，先按照本手册完成本地剪辑。

> 重要：当前阶段不把平台预设、BGM 模板、游戏 HUD 保护、批量字幕模板等规划能力当作已交付功能。本手册只介绍当前界面中已经存在的可用操作。

## 2. 开始前准备

### 2.1 准备素材

建议提前准备：

- 至少一个视频文件；
- 可选：一个音频文件；
- 可选：几张图片；
- 可选：一段需要自动生成字幕的视频或音频。

建议第一次使用时选择一个较短的视频进行练习。先复制一份练习素材，避免误操作影响原文件。

Vortex Cut 会在项目中登记素材。导入同一素材第二次时，软件可能提示素材已经存在；这不是程序崩溃，直接使用素材列表中的已有项目即可。

### 2.2 当前最安全的使用模式

第一次使用建议只进行以下操作：

- 项目创建与素材导入；
- 本地时间线编辑；
- 本地转录（需要已经安装本地转录模型）；
- 权威预览；
- 本地导出。

第一次使用不需要：

- 配置 Provider；
- 输入外部服务密钥；
- 测试 Provider 连接；
- 使用 AI 粗剪或 AI 修改；
- 使用真实图片生成。

## 3. 启动与退出

### 3.1 开发模式启动

如果你使用的是当前仓库中的开发版本：

1. 打开 PowerShell；
2. 执行：

```powershell
cd <仓库根目录>
pnpm dev
```

3. 等待 Vortex Cut 窗口打开；
4. 保持启动它的 PowerShell 窗口运行。

### 3.2 启动注意事项

- 一次只启动一个 `pnpm dev`；
- 不要同时打开多个 Vortex Cut 开发窗口；
- 不要在软件正在加载时连续点击刷新；
- 如果页面显示“Core 连接中”，先等待几秒；
- 如果项目、素材和转录列表都加载失败，按照“第 12 节：本地连接断开”处理。

### 3.3 正确退出

1. 先关闭 Vortex Cut 窗口；
2. 回到运行 `pnpm dev` 的 PowerShell；
3. 按 `Ctrl + C` 停止开发服务。

不要通过同时启动第二个开发服务来解决加载问题。

## 4. 界面快速认识

进入项目后，界面大致分为以下区域：

| 区域 | 作用 |
| --- | --- |
| 顶部项目栏 | 创建、选择、重命名、归档项目；查看保存状态 |
| 顶部操作区 | 打开镜头需求、模拟生成验证、真实图片生成、撤销/重做、生成预览、导出 |
| 左侧素材区 | 导入和管理素材；查看本地转录模型与任务 |
| 左侧“素材/转录”标签 | 在素材列表和转录列表之间切换 |
| 中间预览区 | 交互预览、权威预览、播放和拖动播放位置 |
| 中间布局区 | 调整当前片段的布局 |
| 下方时间线 | 查看视频轨道和字幕轨道，选择片段进行编辑 |
| 右侧属性区 | 编辑所选 Clip 或 Caption 的具体属性 |
| 渲染与导出区 | 查看预览、导出任务和已经生成的文件 |

### 4.1 两种预览模式

- **交互预览**：用于快速查看素材和当前编辑状态，适合边改边看；标记为“非权威”。
- **权威预览**：由本地渲染任务生成，适合在导出前进行最终确认。

如果时间线发生变化，原来的权威预览可能显示为“已过期”。这时应重新生成权威预览。

### 4.2 保存状态

顶部会显示保存状态：

- **已保存**：当前修改已经写入项目；
- **保存中**：正在保存，请稍等；
- **保存失败**：当前修改没有可靠保存，应刷新或重试；
- **草稿冲突**：项目在其他操作中发生变化，需要先处理冲突。

进行下一步操作前，建议等待状态回到“已保存”。

## 5. 第一个项目：从零完成一条视频

下面是一条最推荐的练习路线。它不要求调用外部 AI Provider。

### 第一步：创建项目

1. 在顶部找到“项目名称”输入框；
2. 输入项目名称，例如“我的第一个视频”；
3. 点击“创建”；
4. 在“当前项目”下拉框中确认已经选中刚刚创建的项目。

项目创建后，顶部会显示项目名称和项目状态“活动”。只有活动项目可以编辑。

### 第二步：导入视频

1. 确认左侧当前位于“素材”标签；
2. 在“素材工作区”点击“导入 video”；
3. 在系统文件选择窗口中选择视频；
4. 确认选择并等待素材出现在素材列表；
5. 确认素材状态显示为“可用”。

如果需要，还可以点击“导入 image”导入图片，或点击“导入 audio”导入音频。

### 第三步：把视频放入时间线

素材导入后，在素材列表对应行点击“追加”按钮：

- 如果当前还没有时间线，软件会根据素材创建时间线；
- 如果已经有时间线，素材会追加到时间线末尾。

你也可以点击“创建空时间线”，再逐个追加视频或图片。

时间线创建后，中间下方会出现（自上而下）：

- 文本/字幕轨（`C1`）与用户新增的轨道；
- `V1`：主视频轨道（固定）；
- `A1`：音频轨道（固定）。

### 多轨道操作（剪映式）

- **添加轨道**：点击时间线左上角"＋"按钮，选择"视频轨道"或"文本轨道"。新轨道出现在字幕轨上方；
- **删除/换位轨道**：鼠标悬停轨道左侧头部，出现"↑ ↓ 删除"按钮。固定轨道（字幕/主视频/音频）不可删除或移动；
- **轨道属性**：每条轨道左侧头部有一排开关（按类型显示）：
  - 视频/图片轨：类型标识、锁定、隐藏、静音（关闭原声）、独奏（仅播该轨声音）；
  - 文本轨：类型标识、锁定、隐藏（无静音/独奏）；
  - 音频轨：类型标识、锁定、静音、独奏（无隐藏）；
- **跨轨拖动**：按住片段垂直拖动到另一条视频轨即可移动（同轨不允许重叠，跨轨允许叠加）；
- **拖动播放头**：只要鼠标不在素材上，按住时间线任意空白位置左右拖动即可移动播放头；标尺上的圆角手柄也可以直接拖动；Shift+拖拽为框选。

注意：隐藏轨道的内容不参与预览与成片；静音/独奏只影响声音。

### 第四步：添加第二个片段（可选）

1. 再次点击“导入 video”或“导入 image”；
2. 导入完成后，在新素材行点击“追加”；
3. 新片段会出现在时间线末尾；
4. 点击时间线中的片段确认顺序。

### 第五步：播放并检查

1. 在时间线中点击一个片段；
2. 在中间预览区点击播放按钮；
3. 使用播放位置滑块拖动到不同时间；
4. 检查片段顺序、画面和音频。

## 6. 编辑视频片段

### 6.1 选择片段

在时间线的 `V1` 轨道中点击一个片段。选中后，右侧会显示“Clip 属性”。

### 6.2 调整布局

在“Clip 属性”中可以选择：

- **模糊背景**：保持画面完整，在两侧或上下使用模糊背景填充；
- **裁切填满**：裁切画面以填满目标区域；
- **完整适配**：尽量完整显示原画面。

也可以在预览区下方的布局切换中直接选择布局。

### 6.3 裁剪片段起止时间

选中视频片段后，在“Clip 属性”中修改：

- **源起点（秒）**：从原视频的哪一秒开始；
- **源终点（秒）**：使用到原视频的哪一秒结束。

操作方法：

1. 输入新的起点或终点秒数；
2. 点击输入框外部，让修改提交；
3. 等待顶部保存状态变为“已保存”；
4. 播放检查结果。

起点必须早于终点，且不能超出原视频长度。

### 6.4 拆分片段

1. 在 `V1` 轨道选中一个视频片段；
2. 点击时间线工具栏中的“拆分片段”按钮；
3. 软件会把该视频片段拆成两段；
4. 播放检查拆分结果。

当前界面的“拆分片段”会按当前片段的中间位置拆分，不是按照播放滑块所在位置拆分。如果需要精确位置，请使用“源起点”和“源终点”编辑。

### 6.5 自由拖动与移动片段

`V1` 视频轨道支持自由定位（与剪映覆盖轨 / OpenCut 一致）：

1. 直接用鼠标**左右拖动**片段，拖到哪里就放在哪里；
2. 片段之间**允许留空隙**，播放到空隙时画面为黑帧；
3. 同一轨道上**不允许重叠**：拖到与其他片段重叠时，会自动吸附到最近的空隙（与邻居贴齐）；
4. 拖动时有黄色吸附辅助线：对齐其他片段边缘、播放头与网格；
5. 也可以选中片段后用“向前移动”/“向后移动”按钮**逐帧微调**位置；
6. 框选或 Shift+点击选中多个片段后整体拖动，选区作为刚体平移，同样受无重叠钳制。

注意：

- 移动片段不会改变其他片段的位置（没有自动合拢）；
- 若两片段之间出现了空隙，原来加在它们之间的转场会暂时“休眠”——时间线上不显示、渲染时跳过；把片段重新贴齐后转场自动恢复；
- 空隙处不能添加转场（转场只加在首尾相接的两个片段之间）。

### 6.6 删除片段

1. 选中要删除的片段；
2. 点击时间线工具栏中的“删除所选”；
3. 确认片段从时间线中移除；
4. 如有需要，使用顶部“撤销”恢复。

删除时间线片段不会自动删除素材库中的原始素材。

反过来，在素材库中删除素材时，如果它已被添加到时间线，软件会弹出确认框提示：
确认删除后，时间线上引用该素材的片段（含关联字幕与转场）会一并删除。
此操作不可撤销，请谨慎确认。

### 6.7 调整音频

选中视频片段后，在“Clip 属性”中可以：

- 勾选或取消“启用音频”；
- 调整音频增益；
- 播放检查声音大小。

如果一个片段不需要声音，可以取消“启用音频”。

### 6.8 锁定片段

当某个片段已经调整好、不希望被后续操作影响时：

1. 选中该片段；
2. 点击时间线工具栏的锁定按钮；
3. 片段会显示锁定状态。

锁定后，移动、删除、直接编辑和关联字幕编辑可能会被禁用。需要修改时先点击“解锁片段”。

### 6.9 撤销与重做

- 点击顶部“撤销”回退最近一次已保存的时间线修改；
- 点击顶部“重做”恢复被撤销的修改。

如果按钮不可用，说明当前没有可以撤销或重做的操作。

## 7. 使用本地转录制作字幕

本节是可选流程。如果你只需要剪画面，可以跳过本节。

### 7.1 检查本地转录模型

在左侧素材区下方找到“本地转录模型”。模型可能显示：

- 未安装；
- 下载中；
- 校验中；
- 已就绪；
- 下载失败；
- 已暂停。

只有显示“已就绪”的本地模型，才能开始本地转录。

如果模型未安装：

1. 点击“下载模型”；
2. 阅读许可证；
3. 如同意，勾选接受许可证；
4. 点击“确认并下载”；
5. 等待模型完成校验并显示“已就绪”。

模型下载属于本地模型准备流程，不等于调用 AI Provider。下载过程中请确保网络和磁盘空间正常，并按照软件提示操作。

### 7.2 创建本地转录

1. 在素材列表中找到视频或音频；
2. 点击该素材行的“转录”按钮；
3. 在弹窗中选择语言：
   - 自动检测；
   - 中文；
   - English；
4. 可选勾选“生成词级时间戳”；
5. 点击“开始转录”；
6. 在左侧“任务”区域查看进度。

转录任务可能显示“排队中”“运行中”“已完成”或“失败”。任务运行时不要重复点击“开始转录”。

### 7.3 查看转录

1. 点击左侧“转录”标签；
2. 每条转录显示为一行记录：素材名 + 状态（就绪 / 已过期 / 失败）+ 语言，右侧是垃圾桶图标按钮（删除转录）；
3. 点击记录本身，在“原始转录”窗口中查看带时间范围的片段。

原始转录是只读记录。后续字幕修改不会覆盖原始转录。

> 每条转录只出现一行：点开记录只是打开查看窗口，不会在列表里新增第二条同名记录。
> 垃圾桶按钮按记录常驻，无需先点开该记录。若其片段已被时间线字幕引用，删除会被拒绝。
> 确认删除后记录立即从列表消失（不需要等待刷新）；同一素材的其它转录不受影响。

### 7.3.1 转录文字看起来“乱码”时

本地语音识别由 Whisper 模型完成，模型档位（当前为 **Whisper Tiny**）直接决定准确度：

- 如果素材以**音乐/环境声**为主、人声很少，Tiny 容易把音乐“听”成重复的无意义短句
  （例如连续多段同样的两三个字）。软件已启用语音活动检测（VAD）先切掉非语音段，
  这类幻听重复段会被过滤，但无法凭空补出不存在的人声。
- 如果**人声清晰**仍然错字较多，通常是模型档位偏低，而不是音频质量问题；
  换用更大的模型档位可显著改善。
- 若某段明显是音乐或噪声却被转成了文字，属于模型能力边界，请手动删除该片段
  （不勾选即可，不会进入时间线）。

### 7.4 从转录片段创建时间线和字幕

1. 在“原始转录”窗口中勾选需要使用的片段（可用“全选 / 清空”）；
2. 点击“追加所选片段”；
3. 如果还没有时间线，软件会根据所选转录创建时间线；
4. 如果已经有时间线，所选片段会追加到时间线末尾；
5. 软件会同时创建对应字幕；
6. 返回“素材”或时间线区域播放检查。

建议第一次只勾选少量连续片段，确认结果后再追加更多内容。

### 7.5 编辑字幕

1. 在 `C1` 字幕轨道中点击字幕块；
2. 右侧会显示“Caption 属性”；
3. 可以修改：
   - 文本；
   - 开始时间；
   - 结束时间；
   - 字幕预设；
4. 修改文本或时间后点击输入框外部；
5. 等待保存状态变为“已保存”；
6. 播放检查字幕是否与画面和声音同步。

可用字幕预设包括：

- 默认底部；
- 游戏安全区；
- 高对比。

### 7.6 删除字幕

1. 在 `C1` 轨道中点击字幕块；
2. 点击“删除所选”；
3. 播放检查对应字幕是否消失。

如果字幕所属视频片段已锁定，可能需要先解锁视频片段。

## 8. 预览与最终确认

### 8.1 先检查交互预览

在编辑过程中，使用“交互预览”快速检查：

- 片段顺序；
- 裁剪起止点；
- 画面布局；
- 音频开关和音量；
- 字幕内容与时间。

交互预览用于快速操作，不等同于最终输出文件。

### 8.2 生成权威预览

建议导出前生成一次权威预览：

1. 确认时间线中至少有一个片段；
2. 确认顶部状态为“已保存”；
3. 如果出现草稿提示，先点击“恢复”或“丢弃”，处理完再继续；
4. 点击顶部“生成预览”；
5. 等待“权威预览”任务完成；
6. 切换到“权威预览”模式；
7. 播放完整视频或重点片段。

如果时间线在生成预览后又被修改，旧预览会标记为“已过期”，需要重新生成。

### 8.3 预览检查清单

导出前至少检查：

- 开头是否正确；
- 结尾是否正确；
- 是否有黑屏或意外空白；
- 片段之间的顺序是否正确；
- 音频是否需要静音或调整；
- 字幕是否超出画面；
- 字幕是否与讲话同步；
- 画面是否被错误裁切；
- 时间线是否已经保存。

## 9. 导出最终视频

### 9.1 单个视频导出

1. 确认时间线已经保存；
2. 建议先完成权威预览；
3. 点击顶部“导出”；
4. 在系统窗口中选择导出文件夹；
5. 确认导出；
6. 在“渲染与导出”区域查看任务状态；
7. 等待任务显示“已完成”。

导出过程可能需要一段时间，请不要重复点击“导出”。

当前编码模式有：

- **自动编码**：由软件选择可用编码方式；
- **软件编码**：使用更兼容但可能更慢的方式编码。

第一次使用建议保持“自动编码”。如果自动编码失败，再尝试“软件编码”。

### 9.2 查看导出结果

导出成功后，在“渲染与导出”区域找到对应记录，可以：

- 点击播放按钮，在软件内查看导出视频；
- 点击“打开导出”，用系统默认程序打开文件；
- 点击“定位导出”，打开导出文件所在文件夹。

导出记录会显示目标名称、状态和编码方式。请以导出任务显示“已完成”为准，不要只根据任务开始就判断成功。

### 9.3 导出失败或中断

如果任务显示失败、取消或中断：

1. 先记录界面上的安全提示；
2. 检查磁盘空间和导出文件夹权限；
3. 回到时间线确认仍然存在有效片段；
4. 必要时重新生成权威预览；
5. 再尝试导出一次。

不要复制或发送完整底层异常日志。

## 12. 常见问题处理

### 12.1 提示“素材已存在于当前项目中”

说明该素材已经导入过。

处理方法：

1. 关闭提示；
2. 在素材列表中查找已有素材；
3. 点击已有素材的“追加”按钮；
4. 不要连续重复导入同一素材。

### 12.2 项目、素材或转录列表加载失败

这通常表示桌面窗口暂时无法连接本机 Core 服务。

处理方法：

1. 关闭所有 Vortex Cut 窗口；
2. 回到启动开发服务的 PowerShell；
3. 按 `Ctrl + C`；
4. 等待服务停止；
5. 只执行一次：

```powershell
cd <仓库根目录>
pnpm dev
```

6. 只使用这一次启动的窗口。

不要同时打开第二个终端启动 `pnpm dev`，不要直接删除项目数据或数据库。

### 12.3 页面显示“Core 连接中”很久

先等待几秒。如果仍然没有变化：

1. 不要连续点击按钮；
2. 关闭软件窗口；
3. 按“第 3.3 节”正确退出；
4. 只重启一次；
5. 如果仍然失败，记录“哪个页面无法加载”和“界面上的第一行安全提示”。

### 12.4 导入后素材显示“缺失”或“已变更”

说明素材当前位置发生变化，或者文件内容发生变化。

处理方法：

1. 点击素材列表上方的“刷新素材库”按钮（搜索框右侧），重新检查所有素材文件；
2. 如果素材文件只是被移动或改名，重新导入该文件即可（软件会按内容识别，不会产生重复素材）；
3. 如果本地文件确实已删除且不再需要，再次点击“刷新素材库”：
   未被时间线引用的素材会自动从列表中清除；
4. 如果素材仍被时间线片段引用，它会保留在列表中并显示“缺失”，此时可先从时间线移除相关片段，再刷新清除；
5. 处理完成后，素材状态会恢复为“可用”，可继续追加到时间线。

### 12.5 “生成预览”和“导出”按钮不可用

常见原因：

- 还没有创建时间线；
- 时间线中没有片段；
- 存在未处理的草稿；
- 当前项目不是活动状态。

处理方法：

1. 确认素材已经追加到时间线；
2. 检查顶部保存状态；
3. 如果有草稿提示，点击“恢复”或“丢弃”；
4. 等待状态变为“已保存”；
5. 再生成预览或导出。

### 12.6 修改后出现草稿提示

草稿表示软件保存了尚未形成正式 Revision 的编辑状态。

- 点击“恢复”：继续使用上次未完成的编辑；
- 点击“丢弃”：放弃这份草稿，回到最近一次正式保存的时间线。

如果提示“草稿冲突”，不要直接继续编辑。先刷新当前时间线，确认没有其他操作正在修改项目。

### 12.7 本地转录按钮无法开始

常见原因是本地转录模型还没有“已就绪”。

处理方法：

1. 查看“本地转录模型”区域；
2. 如果模型未安装，先下载并等待校验完成；
3. 如果模型正在下载，等待任务结束；
4. 如果模型下载失败，先处理下载任务，再重试转录。

### 12.8 转录任务失败

1. 在“任务”区域查看任务状态；
2. 确认素材状态为“可用”；
3. 确认本地模型为“已就绪”；
4. 使用“重试转录”；
5. 不要重复创建多个相同转录任务。

### 12.9 导出文件找不到

1. 回到“渲染与导出”区域；
2. 确认任务状态为“已完成”；
3. 点击“定位导出”；
4. 检查导出文件夹是否有写入权限；
5. 不要仅凭任务已经开始就判断文件已经生成。

## 13. AI 和 Provider 功能说明

> **【2026-09-24 补记】本节此前只覆盖 4 项 AI 功能，已落后于当前实现。**
> 当前**已交付**的 AI 能力清单统一声明在 [`../STATUS.md`](../STATUS.md) §3「能力边界」——
> 本手册不再复述完整清单，只补充用户操作层面的说明。**本节与 STATUS.md 冲突时以 STATUS.md 为准。**

这些功能不是完成普通剪辑所必需的。

### 13.1 AI 粗剪

AI 粗剪会先让你填写制作信息，然后准备一份外传确认。只有在你明确确认发送后，才可能调用已配置的外部 Provider。

第一次使用请：

- 可以打开窗口查看界面；
- 不要创建 Provider；
- 不要输入密钥；
- 不要点击连接测试；
- 不要点击“确认发送”；
- 不要点击“我确认发送以上内容”。

### 13.2 AI 修改

AI 修改会根据你的修改指令生成时间线修改提案。提案不会自动修改正式时间线，但“确认并发送一次”会触发受控外传流程。

第一次使用请不要点击最终发送按钮。

### 13.3 真实图片生成

“真实图片生成”是 Provider 相关功能，不属于基础视频剪辑流程。它可能产生网络外传和费用，使用前必须确认 Provider、内容、费用和隐私范围。

### 13.4 模拟生成验证

“生成验证（模拟）”用于受控验证，不等于真实图片生成。除非你明确知道要验收什么，否则第一次学习剪辑时可以跳过。

### 13.5 AI 助手（多步会话）

AI 助手是一个对话框：你用一句话描述想怎么改，它会分步完成，**每一步都可以单独查看差异**。

- 每次会话最多执行 6 步，每步成功都会留下一个可撤销的版本；
- 如果某一步失败，它会带着失败原因重试，**失败的那一步不会改动你的时间线**；
- 面板会显示这次会话消耗的 token 与费用；
- 会话过程中如果时间线被其他操作改动，会话会安全中止，不会写坏结果。

和“AI 修改”的区别：AI 修改是**单次**提案；AI 助手是**多步**，适合“先剪短、再加转场”这类复合要求。

### 13.6 本地视频分析

对素材做一次本地分析，提取镜头切点、运动强度、清晰度、亮度、音频能量，以及画面中是否出现人脸。

- **全程在本机完成，不联网、不上传任何内容**；
- 分析结果用于 AI 粗剪的选段排序——**没有语音的素材（孩子跑动、宠物、风景）也能被 AI 选中**；
- 分析在后台任务中执行，可以取消。

### 13.7 设置（含网络代理）

设置窗口用于配置 Provider 网络代理：跟随系统代理（默认）/ 自定义代理地址 / 直连。

- 代理设置**重启后生效**，窗口会如实提示当前是否需要重启；
- 如果你在国内直连境外 Provider 超时，通常是代理没配好。

### 13.8 导出与封面

导出窗口可选择分辨率与帧率（多平台 Profile），并可设置项目封面（从时间线截帧）。

## 14. 隐私与安全注意事项

- 普通本地剪辑、时间线编辑、预览和导出不要求真实 AI Provider；
- 不要在截图或问题反馈中暴露密钥、令牌、授权信息或原始响应；
- 不要把完整底层异常日志发送给他人；
- 不要把本地媒体的完整路径贴到公开渠道；
- 不要把原始字幕或转录正文发送到不必要的地方；
- 使用外部 Provider 前，先阅读确认窗口中列出的目标、模型、字段和费用提示；
- 只有你明确确认后，才允许进行外部发送；
- 如果不确定某个按钮是否会产生网络调用或费用，先不要点击。

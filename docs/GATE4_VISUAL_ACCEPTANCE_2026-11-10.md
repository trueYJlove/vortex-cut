# GATE-4 视觉重做验收记录

日期：2026-11-10

## 参照对象与取舍

参照 OpenFilm 的实际设计系统（`packages/openfilm/studio/ui/src/globals.css`）。

**关键事实**：OpenFilm 的主主题是**浅色**（`--bg-app: #e4e4e8`、`--bg-panel: #fbfbfc`），
暗色是变体。直接照搬色值会变成另一个产品。因此本次提取的是**结构与原则**：

| 维度 | OpenFilm（暗色变体） | 我们（改造后） |
|---|---|---|
| 窗口底 | `#141414` 中性灰 | `#141416` 中性灰 |
| 面板 | `#181818` | `#18181b` |
| 抬升面 | `#202020` | `#202024` |
| 强调色 | `#00c1cd` 青 | `#35d6ae` 品牌青（保留） |
| 表面层级 | 4 级 | **7 级 → 4 级** |

## 改了什么

1. **表面层级 7 → 4**：canvas（预览井，最深）→ shell（窗口底/顶栏/时间线）→ panel（左右面板）
   → raise（卡片/控件）。深色界面里层级越多越显脏，四级已足够表达秩序。
2. **去除蓝色调偏置**：原底色偏蓝（`#101518` / `#161d20` / `#1e272a` 等），改为中性灰
   （`#141416` / `#18181b` / `#202024`）。共清理 5 处残留硬编码蓝色调（`#12181b`、
   `#101619`、`#1a2225`、`#06090a`、`#090d0f`），全部改为引用令牌。
3. **预览井中性化**：`rgb(6,9,10)`（偏绿黑）→ `rgb(13,13,15)`，与外层同族但仍最深，画面继续浮起。
4. **强调色克制**：品牌青只用于选中态、主操作按钮、中央播放键，不做装饰性使用。
5. **移除预览井的 `inset` 阴影与 `60px` 大内阴影**：Clean 的边界由一层描边完成，
   叠两层阴影会让预览框显得厚重。

## 验收证据

- **几何零变化**：顶栏 36px、左栏 280px、右栏 336px、时间线 230px、播放条 40px、
  主播放键 34px 且为 `rgb(53,214,174)` —— 与改造前逐项一致
- **窄窗口**：1024×720 下 `docOverflow = 0`，无横向溢出
- **弹窗隔离**：设置弹窗仍为 `--dlg-primary: #35d6ae`、背景 `rgb(23,27,30)`、圆角 12px，
  未被新令牌影响
- **全量检查**：`pnpm lint` / `typecheck` / `build` 通过；`pnpm test` 143 文件 / 1327 测试通过
- **对照页**：`docs/ui-mockups/main-workspace/review.html`（Before/After + 窄窗口 + 弹窗三张）

## 与目标的偏差（如实记录）

原始目标中的两处，在实施中被证据改变了做法：

1. **「卡顿片段自动补渲染」→ 判定不做**。实测代理路径解码 p95 已降至 7.2 ms（实时预算 33.3 ms 的 22%），
   没有"画不动"的区间可补；且实现需给 Core 增加区间渲染与新的 artifact kind，
   会触发迁移与 `STATUS.md` 同步，与"不改 Python Core 架构"硬约束冲突。细节见 GATE-1 记录。
2. **「主界面组件拆分」→ 只抽取底栏**。`App.tsx` 有 265 个状态、28 个 effect、11 个测试直接挂载；
   全面拆分需重组状态生命周期，与"行为不变"验收冲突。已抽取 `WorkspaceFooter` 并记录
   顶栏/三栏的前置条件。细节见 GATE-2/3 记录。

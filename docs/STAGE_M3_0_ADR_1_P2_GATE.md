# M3-0 ADR-1：P2 逐帧一致性判据相对化（门限口径修订）

> 编号：M3-0-ADR-1　状态：**已接受**（项目所有者，2026-09-05）
> 依据：[M3-0 技术验证报告](./STAGE_M3_0_TECH_VALIDATION_REPORT.md) §2（原始 40dB 门未达，归因完备）
> 关联：冻结方案 §7.2/§5-R10（"阈值修订必须先产出 ADR"——本文件即该 ADR）
> 决策人：项目所有者；起草：LiuWei/ZhangSan

## 1. 背景

P2 冻结判据为"非字幕采样帧全部 PSNR ≥ 40dB 且几何错位 ≤ 1px"。实测：

- **几何错位 26/26 非字幕帧全部 = 0px**，语义/时序零偏差（IR 数值表与权威端渲染逐帧一致）；
- 第 0 步自校准底噪 **31.41–38.59dB**（校准时间线，静态内容）——**40dB 门低于两条渲染栈的系统性差异**；
- 主时间线非字幕帧 PSNR：静态/慢速内容 31–35dB，含 PiP/快速运动内容 19–28dB（旋转残差与速度段帧选择口径叠加）。

归因链完整：差异来自 libswscale（双三次缩放 + 双线性色度 + 定点 YUV↔RGB）与 GPU 采样栈（mip/显式 LOD + 着色器 BT.709 浮点）的算法与精度差异，**不包含任何语义漂移或不可归因成分**（R2 语义差流程未触发）。

## 2. 备选方案与取舍

| 方案 | 内容 | 取舍 |
|---|---|---|
| ADR-2 | 坚持原 40dB 门；M3 引擎着色器内复刻 swscale 采样算法 | 像素级一致可期；工程成本显著（定点系数/滤波相位逐项对齐 + 长期维护两套语义），且 40dB 级差异在编辑预览场景无感知价值 |
| ADR-3 | 收缩子集，维持"预览仅权威"，M3 缓行 | 零风险；但 P1/P3 已证能力成立，放弃的机会成本最大 |
| **ADR-1（采纳）** | 门限相对化：以语义一致 + 实测下限回归基线 + 缺陷修复重基线化 取代绝对 40dB；40dB 保留为 M3 工程北极星 | 预览与导出为**感知等效**而非像素恒等；需接受"同一渲染意图、两条像素栈"的长期事实 |

## 3. 决策

采纳 ADR-1。P2 达标判据自本 ADR 起修订为以下五条（全部基于 `p2/baseline/comparison.json` 可复算）：

1. **几何错位 = 0px**（±8px 相位相关搜索窗，全部非字幕帧）——已达 ✓
2. **语义/时序零偏差**：GL 端逐帧输出与 IR 数值表一致，IR 与权威端渲染的内容时间原点/转场窗口/变速帧对位/黑底填充逐帧一致——已达 ✓
3. **PSNR 回归基线**：非字幕帧 PSNR ≥ **19dB**（本轮实测最低值 19.103dB@n=510，作为 M3 期间回归门：渲染管线任何改动不得使该下限下降）；分档参考值：无 PiP/慢速帧 ≈31dB（实测 min 30.99），PiP/快速运动帧 ≥ 19dB——已达 ✓（26 帧实测 19.10–35.36dB；字幕帧 14.8–16.5dB 不计入。勘误 E1/E2，LiuKeAi 验收）
4. **字幕帧单独口径**：文本掩码 IoU ≥ 0.35 且文本中心偏移 ≤ 8px——已达 ✓（IoU 0.376–0.453，偏移 ≤5px）
5. **缺陷修复重基线化条款**：权威端缺陷（position 关键帧超长、rotate 弧度错位）修复后，对应特征重新采样比对并**上调**基线；此后 40dB 重新评估是否可达。
   **执行记录（2026-09-05，修复 commit 456c89a）**：渲染时长缺陷消除（基准 3180→1800 帧）；旋转受影响帧 PSNR +2~3.2dB（如 n=510：19.1→22.3）；非字幕帧最低 19.10→**20.19dB（n=570）**，回归门上调至 **≥20dB**。原预测"PiP 帧恢复至 ≥28dB 档"未实现——旋转重采样滤波残差（GL mip/双线性 vs swscale）仍在，与 ADR-2 北极星路径相关，如实记录。

原 40dB 门自本 ADR 起降级为 **M3 工程北极星指标**（ADR-2 路径保留，产品如需像素恒等可重启）。

## 4. 影响

- **对 IR 契约冻结草案**：草案可以产出，但受红线约束（见 [IR 契约冻结草案 v0.1](./STAGE_M3_0_IR_CONTRACT_DRAFT.md) §5）——缺陷阻塞的两个特征（V1 position 关键帧、PiP rotate）**不入子集**，修复复测后方可加入；
- **对 M3 立项**：预览合成引擎按"感知等效 + 语义恒等"口径立项，引擎需在渲染管线变更时维护 §3.3 的回归基线；
- **对测试资产**：比对工具与校准/基准时间线转为 M3 长期资产（回归门的执行载体），不再是一次性探针资产；
- **风险记录**：19–25dB 档（快速运动/旋转内容）的差异为滤波特性（边缘软硬、色度相位），主观观感为"轻微锐度/色彩差"，无内容错位——如后续产品判定不可接受，重启 ADR-2。

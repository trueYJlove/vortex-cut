# B11-D(代理降档决策轮)备忘录(2026-09-12)

## 1. 背景与问题

B13-R 判别:F02(900s@640×360@30,27000 帧)Tab WS 16.6GiB 平台为
**Chromium 层有界池高水位**(unique 帧数饱和,~600KB/帧,应用层无泄漏)。
应用侧无可修对象后,唯一可行动的结构性方向 = **降低解码输入分辨率**
(B11 代理,帧字节随像素数缩小,池结构不变、总量降档)。

本备忘录回答:代理降档对 F02 类"长素材"是否真实有效、若有效如何接线。

## 2. D1 spike 设计(工具已入库,待实测)

**方案**:夹具级替换——`F02P` 场景 = 与 F02 完全相同的装配(900 段/900
字幕),仅媒体换为 320×180/900s 源(帧字节 4× 减小)。不动
source-resolver 默认策略,不触发代理作业;测的是同一问题(解码驻留随
帧字节的缩放),侵入最小。

**判定双轨(重要——现行预测器缺分辨率项)**:

| 模型 | 预测值 | 说明 |
|---|---:|---|
| 解析缩放律(本 spike 主判定) | **≈4.4GiB**(0.4GiB base + 27000×600KB×(320×180)/(640×360) = 0.4+3.96) | B13-R"帧字节 4× 减小"假设的直接推论;允差 ±25% → 3.3–5.5GiB |
| 现行 `predictResidencyBytes` 实现值 | 16.35GiB | **实现无 w×h 缩放项**(600KB/帧常数,w/h 仅用于 ≥4× 封顶分支)——已知模型缺口,spike 结果决定是否补项 |

**判定**:
- 实测平台落入 3.3–5.5GiB → 缩放律成立,现行预测器补 w×h 项后可作
  D2 触发线;
- 实测平台 ≈16GiB → 池高水位不随帧字节缩放(按 unique 帧数),**代理
  降档对 F02 无效**——如实登记,B11-D 关闭,方向仅剩 Chromium 上游/
  接受现状;
- 介于两者 → 按实测标定,登记曲线。

**运行**(机器时约 5×(300s 播放+100 seek) ≈ 35min):

```text
python tools/performance/make_fixtures.py --output <空目录> --scenarios F02P --allow-large
AIVS_PERF_RUN=1 AIVS_PERF_SCENARIOS=F02P AIVS_PERF_FIXTURES=<目录> \
  AIVS_PERF_RESULT=<输出目录> npx playwright test apps/desktop/e2e/performance-editor.spec.ts --grep F02P
```

对照基线:`evidence/performance/c20v2-f02-retry-01/`(16,689MiB 平台)
与 G0 F02(16,706MiB)。取 5 轮中位;同机插电关后台。

## 3. D2 三问(待 D1 数据 + LiuWei 裁决)

### 问 1:auto 模式接入驻留预测的降档触发线?

- 现状:B11 规范已留"不支持容器/codec 或**超预算**时请求代理"语义,
  未接任何预算信号;auto 现仅按 codec/容器支持性降档。
- 提案:导入/装配评估一次——`predictResidencyBytes(uniqueFrames, w, h)`
  (补缩放项后)> 档位驻留预算 → auto 请求代理档,否则原源。评估点在
  装配,不在播放中;会话预警(B13-R R3)联动提示。
- 待定值:驻留预算档位(balanced/high 各多少 GiB)——建议以"用户可忍
  受的预览常驻"为产品参数而非技术上限,D1 数据齐后定。
- 备选:不接 auto,仅暴露手动"预览质量:原片/代理"选择(实现小,无
  误降档风险)。

### 问 2:是否增设低于源短边的档位?

- 现状:preview-540/720/1080 对 640×360 源全部禁上采样不生效——F02 类
  小分辨率长源**无代理档可用**。
- 选项:A) `preview-270-v1`(480×270,字节 1.78×↓,质量损失小);
  B) `preview-180-v1`(320×180,字节 4×↓,即 spike 档);C) 不增设,
  小源长素材接受现状(16.6GiB 平台有界且不增长,仅高)。
- 关联:F04(4K)用 preview-540 即得 4×,**大分辨率长源不需要新档**——
  本问只影响"小源长素材"场景的产品取舍。

### 问 3:代理质量降级的 UX 登记

- 沿用 B11 验收口径:"质量变化记录为代理降级,不混同原片质量基准"。
- 待产品定:预览界面的降档可见性(徽标/提示条/仅设置页),以及代理源
  与原源切换时(pause/seek 边界原子切换,B11 已有 binding generation
  机制)的过渡表现。

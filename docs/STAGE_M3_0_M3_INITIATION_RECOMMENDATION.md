# M3 立项建议草案（M3-0-3 交付物，待独立验收）

> 起草：LiuWei，2026-09-05　依据：[M3-0 技术验证报告](./STAGE_M3_0_TECH_VALIDATION_REPORT.md)、[ADR-1](./STAGE_M3_0_ADR_1_P2_GATE.md)、[IR 契约冻结草案 v0.1](./STAGE_M3_0_IR_CONTRACT_DRAFT.md)

## 1. 建议

**M3（预览合成引擎）正式立项**，按"感知等效 + 语义恒等"口径（ADR-1）进入契约冻结与引擎实现。三探针证据：R1 合成能力（任务 0.1–0.4ms 对 33.3ms 预算，余量两个数量级）、R2 一致性（几何 0px、语义零偏差、PSNR 回归基线达标）、R3 寻址（WebCodecs+缓存 p95 ≤ 39ms 全达标）、R4 架构方向（Core 生成 IR / Renderer 只消费，全程无插值二义性）——无一项需要触发回退路线（合成引擎迁出 Renderer 等）。

## 2. 立项范围（v1 建议）

- **IR 契约**：以草案 v0.1 冻结子集为 M3 第一里程碑范围（§4 缺陷阻塞特征在权威端修复复测后按重入条件加入）；
- **引擎形态**：Electron Renderer 内 WebGL2（raw，无渲染框架）+ WebCodecs 解码（worker 手写 BMFF → 建议 M3 评估 mp4box.js 替换以降低维护面）+ 帧缓存；Core 侧新增 IR 投影端点（`render-plan-v1` → 逐帧数值表）；
- **字幕**：M3 期评估统一栅格化器（消除 IoU 层系统差）；
- **交互预览衔接**：编辑态交互预览维持现状（HTML5 video 即时反馈），IR 合成预览作为"权威级实时预览"接入——衔接策略属 M3 设计范围，不在本建议展开。

## 3. 约束（写入立项范围，不得默认豁免）

1. **scrub 编排**：多路并行寻址为引擎设计任务（实测单路 13–40ms，多路顺序 565–592ms）；
2. **渲染循环节拍**：60–100Hz 满速率已实证可达；遥测/诊断（getGPUInfo 类）禁止在渲染循环内调用；
3. **回归基线**：渲染管线变更不得使 P2 回归基线（几何 0px、PSNR ≥19dB、字幕 IoU ≥0.35）下降；
4. **40dB 北极星**：ADR-2 路径保留，产品如需像素恒等可重启；
5. **探针资产转正**：比对工具/基准时间线/素材成为长期回归资产（同冻结方案 §8 一次性纪律解绑，随本建议一并批准）。

## 0. 这条裁决在裁什么

**冻结「W2.3 机位切换规划器」这条产品线**，并让 W2.2 说话人层**停在降级交付（D3）形态**。

**不是**说 W2.2 已解决；**不是说**将来不能重开。它裁的是：
**在「没有可验证素材」这一现状下，继续投入 W2.2/W2.3 的方法研究没有意义。**

## 1. 依据（全部可复算）

### 1.1 精度门从未通过（生产链路）

S3（P128）在生产链路跑 AMI 16 + AISHELL-4 20：**均值线与两语言最差场线全部越线**，
资源门通过（1.57/1.70 s·分钟⁻¹，余量约 6×），且链路等价性已证。

### 1.2 七轮方法研究**全部否证**

| 轮次 | 假设 | 结果 |
|---|---|---|
| P133 | 巨簇内部可分性（ARI 门槛） | 差 **0.0091** 未过 |
| P134 | 改用「ARI 对应可用 DER」的产品锚定 | **C1 未过**（−0.5879），证否 ARI 可作门槛 |
| P136 | 按 K̂ 分档准入 | **四项 FAIL**（V2/V4/N2/N3） |
| P137 | 提高 τ 使 K=1 可达 | **零区分力**（τ=0.70 时假阳 15/27） |
| P137 | 四个廉价面积信号判别人数 | **分布全部重叠** |
| P138 | 换 ResNet34（A 路径） | **修好一档、毁掉另一档**（K=1 改善、K≥2 24/26 退化） |
| P139 | 双模型分歧作判别信号 | **召回 0.333 = 最简单基线** |

### 1.3 唯一有正面信息的发现，也卡在同一个前提上

P138 证明**瓶颈在 embedding**，且 ResNet34 在 K_true=1 上把过分割从 **6/9 降到 3/9**
（`abjxc` K̂ 8→2、DER 0.4964→**0.1268**；`hqyok` 8→2、0.7868→**0.1133**）。

⇒ 但这只能支持「**按素材自动选模型**」，而它要求**先识别「单人 vs 多人」**——
而 P137（四信号重叠）与 P139（分歧无信息）已经**从两个独立角度否证了该前提**。

### 1.4 决定性约束：**已无可盲测素材**

VoxConverse test **216 场全部已读**（P115/P117/P127/P134/P135/P136 并集），**未读 0**；
其余素材**均已读**：AMI 34 meetings、AISHELL-4 20 场（K_true 全 5–7，**无低人数档**）、
`dev_audio/` 0 wav。且实测**下载不可行**：GitHub 直连 18–27 KB/s；
代理 `127.0.0.1:10808` 能通国内站（HTTPS 1.0–1.3 MB/s）但**穿不过 HuggingFace/GitHub**。
用户 2026-10-17 明确：**没有素材可提供**。

⇒ **任何新的方法假设都无法被诚实验证**。在无盲测集时继续产出「候选」= 事后解释。

## 2. 裁决（D1–D4）

### D1 · **W2.3 机位切换规划器：冻结**

- **冻结**：不立项、不实现、不写契约。**当前 W2.3 零代码零文档**（已核：全仓仅 v38
  与 `speaker_service` 中「`multicam_switch` 不得出现在 `usable_for`」的约束注释）；
- **理由**：W2.3 的输入是 speaker turn，而 turn 的 `quality_status` **恒为 `unvalidated`**
  （S3 判不过）。门 §2 已冻结「W2.3 不得消费未验证轮次」⇒ **在其准入被满足前，W2.3 不可开工**；
- **解冻条件（先写死，防模糊重开）**：见 §3。

### D2 · **W2.2 说话人层：停在 D3 降级交付形态（长期态）**

- 交付形态不变：全量输出 + 机器可读标注（`quality_status='unvalidated'`、
  `usable_for=['reference']`）；
- **本 ADR 不改任何代码、不改迁移、不改契约**；
- 该形态的正当性由降级门 §1 冻结，**本 ADR 不重复其定义**（Rule 5）。

### D3 · **P132（A4 下游拒绝测试）：降级为「条件性待办」，保持开放**

- 它原本是 W2.3 立项门的前置条件。W2.3 冻结后，它**没有当下交付对象**；
- **但不撤销**：一旦 §3 的解冻条件被满足，它是**第一个**必须补的项；
- ⇒ 状态保持 ⏳，并在其行内注明「**因 D1 冻结而无当下对象**」。

### D4 · **P84（真实多机位素材）：保持 ⏳ 未取证**

- 用户已明确当前**无法提供**；W2.1 验收项 9 继续如实标「未取证」；
- **禁止**以合成素材顶替（既有纪律不变）。

## 3. 解冻条件（**全部满足才重开**，写死以防模糊重开）

| # | 条件 | 为什么是它 |
|---|---|---|
| **U1** | 取得**至少 30 场**带标注的真实多说话人素材（**口播/对谈优先**），且**未被本仓读过** | 恢复「可盲测」是本仓全部方法研究的前提 |
| **U2** | 该素材上能**先于跑数**写定判据（沿用既有门限表，**不新造常数**） | 防止又一轮「拍门槛」 |
| **U3** | 解决「**单人 vs 多人**」识别问题，**或**明确放弃按人数分档而改用其它准入 | P137/P139 已证这是所有路线的共同前提 |

> **U3 是本 ADR 认为最难的一条**：P137（四个面积信号重叠）与 P139（双模型分歧无信息）
> 是两次独立否证。若重启时没有**新证据**，不得假设它已解决。

## 4. 明确**不**做的事（避免本 ADR 被读成更多）

- **不**撤销降级交付（D3 形态继续是产品交付态）；
- **不**删除任何历史证据、门文档、ADR——它们记录的是**方法**，将来重开要用；
- **不**宣布「说话人分离不可解」——只说**在现有素材与现有方法下不可达精度门**；
- **不**动 W2.1（机位同步）——它已闭环，与 W2.3 解耦；
- **不**改 `latest_migration` / 契约 / 任何生产代码。

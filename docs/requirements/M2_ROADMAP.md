## 项目定位（约束条件）

Vortex Cut 定位于 **AI 驱动、人机共享** 的视频创作工具。因此：
- 所有 UI 操作必须有对应的程序化接口（API/命令），供 AI Agent 调用
- 所有状态变更必须可追踪、可回放
- 设计需兼顾人类操作直觉与机器可调用性

## 阶段 A：基础交互与时间线骨架

### A1. 时间线多轨道渲染引擎
- 实现至少 3 条视频轨道 + 3 条音频轨道的可视化渲染
- 支持片段在轨道间拖拽移动，拖拽时有辅助线/高亮指示目标位置
- 支持自动吸附到相邻片段边界或播放头（吸附距离 ≤ 10px）
- **验收**：拖拽片段到任意轨道，位置正确，吸附生效，预览随之更新

### A2. 素材箱与预览联动
- 素材箱支持缩略图视图和列表视图切换
- 双击素材在预览窗口播放（仅播放，不自动添加到时间线）
- 从素材箱拖拽素材到时间线，自动生成片段，长度与素材一致
- **验收**：拖拽到时间线后片段出现，预览播放正常

### A3. 基础剪辑操作
- **分割（Split）**：在播放头位置将片段一分为二
- **修剪（Trim）**：从片段开头或结尾拖拽裁剪，保留中间部分
- **删除**：选中后按 Delete/Backspace 移除
- **复制/粘贴**：支持 Ctrl+C/Ctrl+V，粘贴位置在播放头或鼠标位置
- **验收**：所有操作即时生效，预览同步，时间线显示正确

### A4. 撤销/重做（编辑操作覆盖）
- 覆盖 A3 中所有操作（分割、修剪、删除、复制粘贴）
- 撤销/重做支持无限步数（或至少 50 步）
- **验收**：任意操作后撤销 5 步，时间线逐步恢复；重做 5 步，逐步重做

## 阶段 B：高级编辑能力

### B1. 片段变速与反向播放
- 片段速度预设：0.25x、0.5x、0.75x、1x、1.25x、1.5x、2x、4x
- 支持自定义速度值（输入框）
- 支持反向播放（倒放）开关
- **验收**：变速后音视频同步（音频变调或保持音高至少实现一种），预览播放正常；倒放效果正确

### B2. 转场系统
- 实现至少 5 种转场：淡入淡出、滑动（左右/上下）、缩放、擦除、溶解
- 转场可拖拽到两个片段之间，转场时长可调（默认 0.5s，范围 0.1~2s）
- 转场在预览中正确渲染，不影响相邻片段内容
- **验收**：时间线显示转场标记，预览播放转场效果正确

### B3. 关键帧动画
- 支持在时间线上为片段添加关键帧（位置、缩放、旋转、透明度四种属性中的至少两种）
- 关键帧在时间线上可视化显示并可拖拽调整
- 播放时属性在关键帧间插值过渡
- **验收**：添加关键帧后预览动画流畅，调整关键帧位置后动画相应变化

### B4. 字幕与文字叠加
- 已有字幕功能增强为独立文字轨道，支持添加多个文字片段
- 文字样式可编辑：字体、字号、颜色、描边（宽度+颜色）、位置（预设顶部/居中/底部 + 自定义坐标）
- 文字片段时长可拖拽调整
- **验收**：添加文字后预览显示正确样式，调整样式即时更新

## 阶段 C：交互打磨与反馈

### C1. 播放头与时间线导航
- 播放头可拖拽，松开后预览跳转到对应帧
- 时间线标尺显示时间刻度（秒/帧），随缩放级别变化
- 左右方向键逐帧步进（1 帧/步），Shift+方向键步进 5 帧
- **验收**：拖拽播放头预览同步，逐帧步进画面逐帧变化

### C2. 任务进度与反馈
- 所有长时间任务（代理生成、导出、AI 处理）显示进度条 + 剩余时间估计
- 估计基于已处理速度和总工作量动态计算
- 任务可取消，取消后清理临时文件
- **验收**：长时间任务进度持续更新，取消后无残留临时文件

### C3. 快捷键系统
- 默认快捷键：
  - 分割：S
  - 删除：Delete/Backspace
  - 复制：Ctrl+C
  - 粘贴：Ctrl+V
  - 撤销：Ctrl+Z
  - 重做：Ctrl+Y
  - 播放/暂停：Space
  - 放大时间线：Ctrl+=
  - 缩小时间线：Ctrl+-
  - 适配时间线：Ctrl+0
- 提供快捷键设置面板，用户可自定义键位
- **验收**：快捷键响应正确，设置面板修改后立即生效

### C4. 时间线缩放与滚动
- 时间线支持缩放（水平方向放大/缩小轨道视图）
- 滚动条或滚轮滚动浏览时间线
- **验收**：缩放后片段显示精度变化，滚动流畅

## 执行与验收规则

- **顺序**：建议按 A → B → C 顺序推进，每个阶段内部可并行开发
- **独立性**：每个任务可独立实施和合并
- **自测**：每个任务完成后，开发者需在本地运行自测并记录结果
- **阶段验收**：A、B、C 各阶段完成后，由 LiuKeAi（或同等角色）执行集中验收
- **验收不通过**：需返回修正，直到满足所有验收条件

## 与 AI 驱动目标的关联

- 每个任务在设计实现时，必须确保其操作可通过 API/命令调用（即 UI 与后端逻辑分离）
- 时间线状态变更需产生可订阅的事件，便于 AI 感知状态变化
- 所有编辑操作需有对应的指令协议定义（可参考现有 TimelinePatch 机制扩展）

统一骨架

  • 标题区：18px 标题、必要说明、右上关闭；21 / 24 / 18px 内边距。
  • 内容区：24px 水平内边距，独立滚动；优先用留白与表面层级分组。
  • 固定底栏：细分隔线，65px 最小高度；滚动时不遮挡操作。
  • 控件：34px 高、7px 圆角；hover 提亮，focus 使用 2px 薄荷青轮廓。

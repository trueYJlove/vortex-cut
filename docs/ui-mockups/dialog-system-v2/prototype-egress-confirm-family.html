步骤 2 · 确认外发（本族核心）

这是隐私边界，信息层次固定为五段，不许按弹窗重排：
① 发什么（字段清单 + 内容预览）② 发给谁（Provider / 模型 / 目标） ③ 花多少（Token 估算 + 费用口径）④ 凭什么可信（哈希 / 有效期） ⑤ 确认动作（勾选 + 按钮）。
关键取舍：勾选框放在内容区、紧贴预览，不和底栏按钮混排—— 混排时用户会跳过勾选直接点按钮。底栏主按钮用 danger 色而非薄荷青， 因为它是「不可逆外发」而不是普通前进。

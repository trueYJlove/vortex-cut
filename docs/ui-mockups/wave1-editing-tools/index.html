剪辑手法（去停顿 · 卡点 · L/J）

把已验收的三个确定性规划器收成用户可完成的闭环：选素材 → 干跑预览 → 生成提案 → 采纳为正式 Timeline。 提案不会自动改时间线；采纳才落 Revision。零外传、无 Provider。

可点击原型

静音灰 / 保留蓝 · 拖阈值实时重画
去停顿
口播视频识别静音段，一键去掉停顿并闭合时间轴。前置：CV 音频能量。
remove_pauses
beat 金刻度 · 切点吸附
卡点
镜头时长对齐 BGM 节拍网格，强拍放重镜头。前置：beat 分析。
beat_sync
画面切线 vs 音频切线错位
L/J cut
画面切点不变，声音提前（J）或延后（L）。词戳优先 ASR。
lj_cut · split_edit

顶栏：标题 + 三页签（去停顿 / 卡点 / L/J）

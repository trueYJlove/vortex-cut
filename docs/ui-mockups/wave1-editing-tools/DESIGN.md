## 0. 目标与边界

把已 e2e 的三个确定性规划器做成「选素材 → 一键规划 → 确认采纳」：

| 手法 | 规划器 | 被测对象 | 核心动作 |
| --- | --- | --- | --- |
| 去停顿 | `remove_pauses` | 口播视频 | 识别静音 → 保留有声段 → 拼时间轴 |
| 卡点 | `beat_sync` | 音乐 BGM + 镜头 | beat 网格吸附 → 强拍重镜头 |
| L/J cut | `lj_cut` | 口播视频 + 词戳 | 画面切点 + 声音提前/延后 |

**不做**：AI Provider、云端、自动成片；**提案不自动改 Timeline**，采纳才落 Revision（与剪辑语法层 P-A 一致）。

## 1. 入口（三处，同一套面板）

```
A. 素材箱 · 视频/音频行 →「剪辑手法」快捷键
B. 右侧属性面板 → 页签「手法」（选中片段时）
C. 工具菜单 →「剪辑语法」→ 手法 Tab（已有入口，本设计收敛为三页）
```

推荐默认 **B**：选中片段上下文最近；A 作发现入口；C 保留给「看全部规划器 / 历史提案」。

## 3. 分页要点

### 3.1 去停顿 `remove-pauses.html`

- 语境：选中**视频片段**（`clip_id`）
- 预览：时间轴上静音（灰）/ 保留（蓝）条；拖动 `energy_threshold` / `min_silence_us` 实时重画
- 参数：`energy_threshold`（默认 0.05）、`min_silence_us`（默认 400ms）、`pad_us`（默认 50ms）
- 空操作：无静音 → noop，**禁用采纳**
- 失败文案：无 CV 音频能量 → 提示先做「AI 信号分析」

### 3.2 卡点 `beat-sync.html`

- 语境：BGM 素材 + 镜头段列表（可拖选）
- 预览：beat 刻度（金）+ 切点（蓝）+ 强拍高亮；`beats_per_shot` 滑杆改变镜头时长
- 参数：`target_duration_us`、`beats_per_shot`（1–16）、`beats_us`（自动自 BGM 分析）
- 缺 beat：提示先对 BGM 分析节拍（或显式导入网格）

### 3.3 L/J cut `lj-cut.html`

- 语境：视频片段 + 画面切点（时间线播放头或列表）
- 预览：词锚点（圆点）+ 画面切线 + 音频切线偏移（J 左 / L 右）
- 参数：`mode` 三态**自动 / J / L**，`offset_us` 300–500ms
- 词戳来源徽标：`asr` / `energy_proxy`（与评测一致，禁止静默混用）

---

## 4. 提案链（三页相同）

1. **干跑预览** → 摘要 + ops 数 + rationale 摘要
2. **生成提案** → 冻结 Diff（clip/caption/lock）
3. **采纳** → `acceptState`；基线漂移则禁用并提示重开

空操作、已采纳、哈希冲突走 `EditingGrammarPanel` 既有失败文案。

## 6. 落地拆分（评审通过后）

1. Desktop：三页壳 + 去停顿流（参数默认值对齐 Core）
2. 卡点流（BGM + 段列表）
3. L/J 流（词锚 + 自动方向）
4. 属性面板「手法」页签 + 素材箱快捷入口
5. 手测清单 + 与 Core 参数/错误码对齐表

**验收（手测）**：三页各走通「干跑 → 提案 → 采纳」；空操作不可采纳；基线漂移提示；零 egress 文案正确。

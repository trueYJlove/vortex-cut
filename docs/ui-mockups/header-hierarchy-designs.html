左上角功能区视觉分层 · 三版方案

现状问题：四个页签、三个导入按钮、两个文本按钮都是同等大小的灰底圆角块，纵向紧贴堆放，没有任何层次信号——扫一眼就是"一堆字"。三版方案用不同的视觉手段建立层次：方案一用背景分区，方案二用剪映式下划线页签 + 大图标卡，方案三用分段控件 + 虚线导入位。均可交互。

现状（对照）

所有元素同权重灰块纵排，页签与按钮无任何视觉区隔。

方案一 · 分区底色 + 胶囊页签 推荐

顶部深色底色带（#12181c）把"导航+导入"圈成一个功能专区，与下方素材列表形成明暗分层。页签改为胶囊分段控件（凹槽底座+选中浮起），导入按钮改虚线边框（"拖放/添加"的通用视觉隐喻），文本按钮降为青色文字链。层次：底色分区 → 胶囊页签 → 虚线导入 → 文字链，四级递减。

方案二 · 剪映式下划线页签 + 大图标卡 最像剪映

页签改为纯文字 + 青色下划线（剪映顶栏样式，最轻量）；导入按钮升级为大图标卡（图标在上文字在下，点击面积大、更像"素材入口"而非按钮）；文本保持文字链。层次靠字号与图标尺度对比建立，整体最接近剪映的素材面板气质。

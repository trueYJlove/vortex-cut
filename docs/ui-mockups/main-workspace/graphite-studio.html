局部与规格DETAILS / 02从真实工作密度出发，不以放大字号换取“精致感”
01 · 素材面板IMPORT / SEARCH / MEDIA

建立秩序：导入为一级任务，文字素材为轻量操作；搜索与素材列表属于同一阅读路径。选中态仅一层青色，不使用发光效果。

02 · 属性面板INFO / STATUS / ACTIONS

先读信息，再做决定：标题、概览、状态与操作分层；项目主操作有明确主次，说明文字保持安静。

03 · 预览工作台CANVAS FIRST / QUIET CHROME

内容优先：画布外框收敛为一层细线；预览设置靠右成组，播放键以轻微品牌色提示而不是抢占画面。预览引擎、时间码、缩放和全屏逻辑完全不变。

04 · 时间线与状态栏RHYTHM / ALIGNMENT / DENSITY

专业感来自一致性：工具按功能分组，图标统一 1.65px 视觉线宽；轨道、标尺、片段沿同一基线对齐。底栏弱化常驻信息，保留所有快捷入口。

实施约束：沿用现有 Graphite / Teal 令牌；统一 8px 间距节奏、6–8px 控件圆角与弱化分隔线；不改功能、面板调整尺寸逻辑、时间线几何、可访问名称及已完成的弹窗。图中“拖放素材”仅说明现有能力，不新增控件。

关于「蒙版和剪映不一样」

语义一致，差异在呈现
蒙版都是「当前片段只显示区域内画面，区域外透出下层」；V2 盖在 V1 上方在成片渲染中已生效。
真正的差异：① 交互预览此前不渲染蒙版/抠像效果，画布上看不出变化；② 属性平铺长列表，可发现性差。
本设计：面板按剪映 IA 分页签 + 画布补蒙版虚线边界与拖拽把手（video.html 可体验）；抠像以棋盘格示意，精确效果引导至权威预览。

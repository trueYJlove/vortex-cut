## 2. 决策材料(两面如实)

**支持默认 on**:
1. 行为正确性:A/B 全场景 off/on 全部断言过;停滞修复后播放/内存与
   v1 逐点一致(F02 WS 16,689 vs 16,706MB;compose 27.4 vs 27.0/s)。
2. 验收门全过:T1(F01/F03 seek -2.0%/-4.1%,门 ≤20%)、T2(F01 +2.6%/
   F02 -10.7%,门 ≤5%;F03 +7.7% 属 v2 manifest 投影固有,独立验收
   已裁决不阻断)。
3. 结构收益:v2 解除 27000 帧全量帧表上限(F02 恰在 27k 上限,长项目
   不再受 27k 限制)、传输有界化(manifest+窗口按需)、C20c(revision
   换 manifest 沿用会话)与 dirty-range 复用的唯一基础——v1 上无法
   建设这些能力。
4. 回退完备:开关保留(`VITE_AIVS_PREVIEW_IR_V2=0` 一键回退 v1,
   v1 路径零改动且 A/B off 轮 ±5% 复测证明其健康)。
5. 遥测完备:window_fetch/ready 四段/驻留计数均已落库,线上问题可归因。

**已知限制(随翻转生效,如实登记)**:
1. **F02 类随机全谱 seek 取窗等待 +111%**(p95 36.5→77.2ms,T1 前后
   持平):v2 窗协议固有,90 窗下邻域命中率 ~6%;绝对增量 <41ms,
   Gate 未设 F02 seek 门。缓解属窗口尺寸/契约层议题,另立工作单。
2. **F03 类长源 ready +0.5s 量级**(manifest 投影随源大小缩放,
   900s→1.8s / 3600s→4.1s):属 Core 投影成本,v2/v1 分段遥测已可
   归因;压缩挂 C20c/下一工作包候选。
3. F02 低频崩溃待查:与 v2 无关联证据(c20v2 轮一次、机制疑似解码/
   上传竞争),S1 诊断前提已备,复现即取证。
4. **基准口径变化(操作面)**:默认翻转后,未来 A/B/基线轮的 v1
   构建必须显式 `VITE_AIVS_PREVIEW_IR_V2=0`(此前"不设变量"即 v1);
   G0 冻结基线为既有二进制证据,不受影响。

增量、ready 投影成本随源缩放)且不在 Gate 门内,留观测不阻塞。
